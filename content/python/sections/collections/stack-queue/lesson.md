# Стек и очередь

После урока вы сможете использовать стек и очередь и выбирать структуру по порядку обработки данных.

> **Фокус**
> - Нужно знать: списки, `append`, индексы и цикл `for`.
> - Нужно уметь: различать LIFO и FIFO, реализуя их на списке.
> - Полезно знать: почему очередь не стоит обслуживать через `pop(0)`.

## 1. Два разных порядка

Стек хранит историю: последним положили — первым забрали. Это правило LIFO. Очередь хранит порядок ожидания: первым пришёл — первым обслужен. Это правило FIFO. Структура выбирается не по названию задачи, а по тому, какой элемент должен выйти следующим. В этой теме это относится к умению: использовать стек и очередь и выбирать структуру по порядку обработки данных.

## 2. Стек: работаем с концом списка

У списка конец доступен быстро: `append` кладёт элемент, а `pop` снимает последний. Поэтому стек удобно использовать для отмены действий и проверки скобок. В этой теме это относится к умению: использовать стек и очередь и выбирать структуру по порядку обработки данных.

```python
stack = []
stack.append('first')
stack.append('second')
print(stack.pop())  # second
```

## 3. Очередь: список и голова

Для очереди добавляйте элементы в конец, а первого ожидающего берите по отдельному индексу `head`. После обслуживания увеличивайте `head`. Так элементы не приходится сдвигать при каждой операции. В этой теме это относится к умению: использовать стек и очередь и выбирать структуру по порядку обработки данных.

```python
queue = []
head = 0
queue.append('ann')
queue.append('bob')
print(queue[head])  # ann
head += 1
```

Позже для готовой очереди пригодится `collections.deque`. Но сначала важно увидеть саму идею FIFO и состояние `head`.

1. Прочитайте команду.
2. Для `+ X` добавьте X в конец списка.
3. Для стека снимите последний элемент; для очереди возьмите элемент по `head` и увеличьте `head`.
4. Проверьте, что в условии не пытаются снять элемент из пустой структуры. В этой теме это относится к умению: использовать стек и очередь и выбирать структуру по порядку обработки данных.

## 5. Частые ошибки

Не путайте `pop()` и `pop(0)`: это разные порядки работы. Не используйте `pop(0)` как обычный способ очереди — он сдвигает остальные элементы. В задаче со скобками закрывающая скобка при пустом стеке означает ошибку сразу. В этой теме это относится к умению: использовать стек и очередь и выбирать структуру по порядку обработки данных.
