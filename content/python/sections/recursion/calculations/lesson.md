## 1. Зачем нужен этот приём

Урок «Рекурсивные вычисления и трассировка» нужен, когда решение зависит не от угадывания ответа, а от ясного порядка действий. Сначала назовите данные, которые меняются на каждом шаге, затем сформулируйте проверку и только после этого пишите программу. Такой подход делает решение объяснимым и помогает заметить крайний случай до запуска. Это важно именно для темы «Рекурсивные вычисления и трассировка».

## 2. Основная идея

Рекурсивная функция обязана иметь базовый случай и шаг, который приближает вход к базе. Трассировка вызовов помогает увидеть, что каждый вызов завершится и как ответы возвращаются назад. В уроке «Рекурсивные вычисления и трассировка» это основной рабочий приём.

```python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)
```

## 3. Разбор по шагам

Начните с маленького входа, для которого ответ можно проверить вручную. На каждом шаге меняйте только те значения, которые действительно описывают состояние задачи. Если ответ выглядит неожиданно, не переписывайте программу сразу: выпишите состояние после первого, второго и третьего шага. Это важно именно для темы «Рекурсивные вычисления и трассировка».

```python
def sum_digits(n):
    if n < 10:
        return n
    return n % 10 + sum_digits(n // 10)
```

## 4. Шаблон решения

1. Прочитайте условие и выделите входные данные.
2. Назовите переменную, список или таблицу, где будет храниться текущий результат.
3. Выполните один понятный шаг для каждого элемента или состояния.
4. Отдельно проверьте пустой, минимальный и пограничный случаи. Это важно именно для темы «Рекурсивные вычисления и трассировка».

## 5. Частые ошибки

Не смешивайте данные входа с ответом, который ещё строится. Не полагайтесь на случайный пример: для «Рекурсивные вычисления и трассировка» полезно отдельно проверить минимальный допустимый вход и случай, в котором нужного ответа нет. Если используется индекс, заранее договоритесь, с нуля или с единицы начинается нумерация. Это важно именно для темы «Рекурсивные вычисления и трассировка».
