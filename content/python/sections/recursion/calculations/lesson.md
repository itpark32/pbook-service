# Рекурсивные вычисления и трассировка

После урока вы сможете трассировать стек вызовов и проверять завершение рекурсии.

Рекурсию не угадывают: строят цепочку или дерево вызовов.
> **Фокус**
> - **Нужно уметь:** раскрывать вызовы до базовых значений.
```python
def f(n):
    if n <= 2:
        return n
    return f(n - 1) + f(n - 2)
```
`f(5)=f(4)+f(3)=(f(3)+f(2))+(f(2)+f(1))`. Сначала дорисуйте дерево до базы, затем складывайте снизу вверх. При `print(n)` до вызова числа появляются на спуске, после вызова — на возврате.

## Цепочка и дерево

Если функция делает один рекурсивный вызов, достаточно цепочки кадров. Два вызова создают дерево: одинаковые значения аргумента могут вычисляться несколько раз. Каждый узел подписывайте аргументом, а листья — значениями базовых случаев.

В выражении `return f(n - 1) + f(n - 2)` сложение откладывается, пока оба вложенных вызова не вернут результаты. Поэтому вычисление идёт в две фазы: раскрытие сверху вниз и сбор ответа снизу вверх.

## Порядок печати

```python
def countdown(n):
    if n == 0:
        print("старт")
        return
    print("вниз", n)
    countdown(n - 1)
    print("вверх", n)
```

До вложенного вызова выводятся `3, 2, 1`, затем база, после вызова — `1, 2, 3`. У каждого незавершённого вызова сохраняется своё значение `n`.

На экзамене сначала вычислите значения базы, затем небольшие значения по возрастанию. Таблица часто компактнее полного дерева, если нужны только результаты.
## Мини-практика
