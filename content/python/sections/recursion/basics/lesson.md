# Основы рекурсии

После урока вы сможете задавать базовый случай и рекурсивный переход.

Функция может вызывать другую функцию, а иногда — саму себя. Такой способ решения называется рекурсией. Он подходит для задач, которые можно свести к такой же, но более простой задаче.

Перед изучением этой главы полезно уверенно понимать [параметры и `return`](/python/functions/basics).

> **Фокус**
> - **Нужно знать:** базовый случай, рекурсивный шаг и порядок возврата результатов.
> - **Нужно уметь:** проверить, что каждый следующий вызов приближает функцию к остановке.
> - **Полезно знать:** рекурсия не всегда лучше цикла; её выбирают, когда она естественно описывает структуру задачи.
>
## 1. Задача внутри такой же задачи

Начнём с обратного отсчёта. Чтобы вывести числа от `n` до `1`, можно:

1. вывести текущее `n`;
2. решить ту же задачу для `n - 1`;
3. остановиться, когда `n` станет равным нулю.

```python
def countdown(n):
    if n == 0:
        print("Старт!")
        return

    print(n)
    countdown(n - 1)


countdown(3)
```

Результат:

```text
3
2
1
Старт!
```

Вызов `countdown(3)` печатает `3` и запускает `countdown(2)`. Новый вызов делает то же самое для `1`, затем для `0`. При `n == 0` функция выполняет `return` и больше себя не вызывает.

## 2. Три обязательные части рекурсии

У корректной рекурсивной функции должны быть три части.

### Базовый случай

Это простейший случай, для которого ответ известен сразу. Он останавливает новые вызовы.

```python
if n == 0:
    return
```

### Рекурсивный шаг

Функция вызывает себя для более простой версии задачи.

```python
countdown(n - 1)
```

### Приближение к остановке

Аргумент должен изменяться так, чтобы однажды попасть в базовый случай. В обратном отсчёте `n` уменьшается на единицу и приближается к нулю.

> **Проверка перед запуском**
> Ответьте на два вопроса: какое значение остановит функцию и почему следующий вызов обязательно приблизится к нему? Если на один из вопросов нет ответа, рекурсия может оказаться бесконечной.
>
## 3. Факториал: результат собирается при возврате

Факториал натурального числа — это произведение всех чисел от `1` до `n`:

```text
4! = 4 · 3 · 2 · 1 = 24
```

Заметим связь:

```text
4! = 4 · 3!
3! = 3 · 2!
2! = 2 · 1!
1! = 1
```

Каждая строка выражает задачу через такую же задачу для меньшего числа.

```python
def factorial(n):
    if n <= 1:
        return 1

    return n * factorial(n - 1)


print(factorial(4))
```

Выполнение делится на две части. Сначала создаются вложенные вызовы, затем результаты возвращаются назад.

| Вызов | Что нужно вычислить | Возвращаемое значение |
|---|---|---:|
| `factorial(4)` | `4 * factorial(3)` | `4 * 6 = 24` |
| `factorial(3)` | `3 * factorial(2)` | `3 * 2 = 6` |
| `factorial(2)` | `2 * factorial(1)` | `2 * 1 = 2` |
| `factorial(1)` | базовый случай | `1` |

Пока `factorial(1)` не вернёт `1`, предыдущие вызовы не могут закончить умножение. Поэтому ответ собирается снизу вверх: `1 → 2 → 6 → 24`.

## 4. Сумма чисел от 1 до `n`

Так же можно определить сумму:

```text
sum_to(4) = 4 + sum_to(3)
sum_to(3) = 3 + sum_to(2)
```

Для нуля сумма равна нулю. Это базовый случай.

```python
def sum_to(n):
    if n == 0:
        return 0

    return n + sum_to(n - 1)


print(sum_to(4))  # 10
```

Проследим вызовы:

```text
sum_to(4)
= 4 + sum_to(3)
= 4 + 3 + sum_to(2)
= 4 + 3 + 2 + sum_to(1)
= 4 + 3 + 2 + 1 + sum_to(0)
= 4 + 3 + 2 + 1 + 0
= 10
```

Здесь хорошо видны все части: ответ для `0`, вызов с `n - 1` и приближение к нулю.

## 5. Что хранит каждый вызов

Каждый вызов функции получает собственное значение параметра. В `factorial(4)` одновременно существуют вызовы со значениями `n`, равными `4`, `3`, `2` и `1`. Они не перезаписывают параметры друг друга.

Незавершённые вызовы ожидают результат более глубокого вызова. Python хранит их в стеке вызовов. Удобно представить стопку тетрадей: последнюю положили сверху и первой забрали обратно.

В главе [«Рекурсивные вычисления и трассировка»](/python/recursion/calculations) мы подробнее разберём дерево вызовов, повторяющиеся вычисления и вывод команд до и после рекурсивного шага.

## 6. Рекурсия и цикл

Факториал легко вычислить и циклом.

```python
def factorial_loop(n):
    result = 1

    for number in range(2, n + 1):
        result *= number

    return result
```

Оба варианта дают одинаковый ответ. Цикл для этой задачи короче по цепочке выполнения и не создаёт много вложенных вызовов. Рекурсивный вариант полезен для понимания идеи и для задач с рекурсивной структурой: обхода дерева, перебора вариантов, обработки вложенных объектов.

Выбирайте рекурсию не ради необычного кода, а когда формулировка «решить задачу через такую же задачу меньшего размера» действительно делает алгоритм понятнее.

## 7. Частые ошибки

### Нет базового случая

```python
def countdown(n):
    print(n)
    countdown(n - 1)
```

Функция продолжит создавать вызовы, пока Python не остановит программу с `RecursionError`.

### Аргумент не приближается к остановке

```python
def countdown(n):
    if n == 0:
        return
    countdown(n + 1)
```

При положительном `n` значение растёт и никогда не станет нулём. Нужно передать `n - 1`.

### Потерян результат рекурсивного вызова

```python
# Ошибка
def factorial(n):
    if n <= 1:
        return 1
    n * factorial(n - 1)
```

В последней строке вычисление есть, но `return` отсутствует. Функция вернёт `None`. Правильно: `return n * factorial(n - 1)`.

### Базовый случай не подходит входным данным

Функция с условием `n == 0` должна получать целое неотрицательное число и двигаться к нулю. Если допустимы отрицательные значения, нужно отдельно определить их смысл или запретить их до вызова функции.

## 8. Как построить рекурсивное решение

Перед кодом заполните три строки:

1. **Самая простая задача:** для какого значения ответ известен сразу?
2. **Уменьшение задачи:** с каким аргументом функция вызовет себя?
3. **Сборка ответа:** как результат меньшей задачи превращается в текущий результат?

Для суммы от `1` до `n` ответы такие:

1. `sum_to(0) = 0`;
2. вызываем `sum_to(n - 1)`;
3. прибавляем текущее `n`.

Этот план полезнее попытки сразу написать функцию целиком.

## 9. Мини-практика

1. **Обратный отсчёт.** Измените `countdown`, чтобы после слова `Старт!` функция вывела `Поехали!`.
2. **Вывод от 1 до `n`.** Напишите рекурсивную функцию, которая выводит числа в возрастающем порядке. Подумайте, где должен находиться `print`: до или после рекурсивного вызова.
3. **Сумма чётных чисел.** Вычислите рекурсивно сумму `2 + 4 + ... + n` для положительного чётного `n`.
4. **Степень числа.** Реализуйте `power(a, n)` для неотрицательного целого `n`, используя правило `aⁿ = a · aⁿ⁻¹` и `a⁰ = 1`.
5. **Количество цифр.** Для положительного целого числа рекурсивно найдите количество цифр. При делении на `10` используйте `//`.
6. **Трассировка.** Не запуская код, выпишите цепочку вызовов и возвратов для `sum_to(5)` и `factorial(5)`.
