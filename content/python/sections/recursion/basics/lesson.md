## 1. Зачем нужен этот приём

## Основная идея

Рекурсивная функция обязана иметь базовый случай и шаг, который приближает вход к базе. Трассировка вызовов помогает увидеть, что каждый вызов завершится и как ответы возвращаются назад. В уроке «Основы рекурсии» это основной рабочий приём. В этой теме это относится к умению: задавать базовый случай и рекурсивный переход.

```python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)
```

Сначала назовите, что хранит каждая ключевая переменная, и проверьте её значение на небольшом входе. Пример ниже показывает именно рабочий механизм этой темы. В этой теме это относится к умению: задавать базовый случай и рекурсивный переход.

```python
def sum_digits(n):
    if n < 10:
        return n
    return n % 10 + sum_digits(n // 10)
```
