# Цикл for и range

После урока вы сможете перебирать известный диапазон значений.

> **Фокус**
> - Нужно знать: `while` и целые числа.
> - Нужно уметь: использовать `range` с границами и шагом.
> - Полезно знать: правая граница `range` не входит в последовательность.

## Когда число повторений известно

`for` сам берёт очередное значение. `range(n)` даёт числа от `0` до `n - 1`.

```python
for i in range(5):
    print(i)
```

## Начало, конец и шаг

`range(start, stop, step)` задаёт начало и шаг. Для движения вниз шаг отрицательный.

```python
for value in range(10, 0, -2):
    print(value)
```

## Частые ошибки

Не включайте правую границу мысленно. При отрицательном шаге начало должно быть больше конца.
