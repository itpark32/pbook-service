# Трассировка программ

После урока вы сможете пошагово определять значения переменных и результат программы.

> **Фокус**
> - Нужно знать: `for`, `if` и накопители,
> - Нужно уметь: пошагово определять значения переменных и результат программы.
> - Полезно знать: сначала выполните Guided 1, затем перенесите приём в Guided 2.

## 1. Зачем нужен этот приём

Здесь важно увидеть конкретный механизм, а не запомнить готовый ответ.

## Основная идея

Программа получает данные через `input`, сохраняет их в переменных и показывает результат через `print`. Переменная нужна, когда введённое значение потребуется больше одного раза или должно получить понятное имя. В уроке «Трассировка программ» это основной рабочий приём. В этой теме это относится к умению: пошагово определять значения переменных и результат программы.

```python
name = input()
print(name)
```

## 3. Разбор по шагам

Трассировка — это таблица «шаг, вход, старое состояние, новое состояние». Она показывает каждое присваивание, а не только итоговый ответ. В этой теме это относится к умению: пошагово определять значения переменных и результат программы.

```python
first = input()
second = input()
print(first + ' ' + second)
```

## 4. Шаблон решения

1. Прочитайте условие и выделите входные данные.
2. Назовите переменную, список или таблицу, где будет храниться текущий результат.
3. Выполните один понятный шаг для каждого элемента или состояния.
4. Отдельно проверьте пустой, минимальный и пограничный случаи. В этой теме это относится к умению: пошагово определять значения переменных и результат программы.

## 5. Частые ошибки

Не пропускайте строку с присваиванием: именно она меняет состояние.

## Проверьте себя

1. Какое состояние меняется после одного шага алгоритма?
2. Какой крайний случай может дать другой ответ?
3. Как объяснить полученный ответ без запуска программы? В этой теме это относится к умению: пошагово определять значения переменных и результат программы.
