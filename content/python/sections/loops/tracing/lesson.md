# Трассировка программ

После урока вы сможете пошагово определять значения переменных и результат программы.

Трассировка — ручное пошаговое выполнение программы с записью значений переменных.

Её цель — не переписать код на бумагу, а зафиксировать состояние программы в ключевых точках. Таблица снимает нагрузку с памяти и показывает первый шаг, на котором рассуждение расходится с кодом.

> **Фокус**
> - **Нужно знать:** значения записывают после выполнения строки.
> - **Нужно уметь:** построить таблицу шагов цикла.
> - **Полезно знать:** трассировка полезнее попытки «угадать» ответ.
>
## 1. Цикл `for`

```python
x = 3
count = 0

for i in range(4):
    x += i
    if x % 2 == 0:
        count += 1
```

| шаг | i | x после `x += i` | `x` чётное | count |
|---:|---:|---:|---|---:|
| 1 | 0 | 3 | нет | 0 |
| 2 | 1 | 4 | да | 1 |
| 3 | 2 | 6 | да | 2 |
| 4 | 3 | 9 | нет | 2 |

## 2. Цикл `while`

Сначала выпишите стартовые значения, затем для каждой итерации: результат проверки, изменения в теле и значение перед следующим условием. Отдельно отметьте шаг, на котором условие стало ложным.

```python
x = 10
steps = 0

while x > 1:
    x //= 2
    steps += 1
```

| проверка | `x` после деления | `steps` |
|---|---:|---:|
| `10 > 1` | 5 | 1 |
| `5 > 1` | 2 | 2 |
| `2 > 1` | 1 | 3 |
| `1 > 1` — ложь | — | 3 |

Последнюю ложную проверку отмечают, но тело для неё не выполняют.

## 3. Трассировка как отладка

Сначала выберите минимальный пример, затем заведите столбец для каждой меняющейся переменной. Записывайте значение после той строки, где оно изменилось. Для ветвления добавьте столбец с результатом условия. Если интересует только ответ, не нужно расписывать неизменные части программы.

Особенно полезны граничные примеры: пустой диапазон, один элемент, равенство на границе, ни одного подходящего элемента.

## 4. Частые ошибки

- пропускать значение 0 в `range(4)`;
- проверять условие до изменения `x`, хотя в коде оно стоит после;
- держать несколько шагов в голове вместо таблицы;
- записывать только изменившуюся переменную и терять состояние.
