# Вложенные циклы

После урока вы сможете строить перебор пар и таблиц вложенными циклами.

Для каждого шага внешнего цикла внутренний выполняется полностью. Так перебирают таблицы, координаты и пары вариантов.

Удобная модель: внешний цикл выбирает строку или первый объект, внутренний перебирает все столбцы или все варианты второго объекта. После завершения внутреннего цикла внешний делает один шаг, а внутренний начинается заново.

> **Фокус**
> - **Нужно знать:** порядок выполнения двух циклов.
> - **Нужно уметь:** перечислить пары `(x, y)`.
> - **Полезно знать:** два цикла часто означают около `n²` действий.
>
## 1. Пары значений

```python
for x in range(3):
    for y in range(2):
        print(x, y)
```

Получатся `(0,0)`, `(0,1)`, затем пары для `x = 1` и `x = 2`. Внутренний `y` каждый раз начинает диапазон заново.

```python
for row in range(1, 4):
    for column in range(1, 4):
        print(row * column, end=" ")
    print()
```

Внешний цикл создаёт строки таблицы, внутренний — значения внутри строки.

## 2. Ограничиваем лишний перебор

Если нужны не все упорядоченные пары, границы можно сузить. Для всех пар разных элементов без повторов:

```python
numbers = [4, 7, 9, 12]

for i in range(len(numbers)):
    for j in range(i + 1, len(numbers)):
        print(numbers[i], numbers[j])
```

Условие `j > i` не допускает пару элемента с самим собой и не повторяет `(4, 7)` как `(7, 4)`. Сначала всегда решите, важен ли порядок пары.

## 3. Сколько будет действий

Диапазоны длины 3 и 4 дают `3 · 4 = 12` выполнений тела. Для двух циклов по `n` элементов получается примерно `n²`. При `n = 1000` это уже миллион сравнений, поэтому для больших данных ищут более быстрый алгоритм.

## 4. Частые ошибки

- ожидать, что оба счётчика меняются одновременно;
- неверно располагать отступы;
- ставить переход строки во внутреннем цикле;
- использовать полный двойной перебор для соседних элементов, где достаточно одного цикла.
