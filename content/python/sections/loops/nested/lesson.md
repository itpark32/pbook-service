## 1. Зачем нужен этот приём

Урок «Вложенные циклы» нужен, когда решение зависит не от угадывания ответа, а от ясного порядка действий. Сначала назовите данные, которые меняются на каждом шаге, затем сформулируйте проверку и только после этого пишите программу. Такой подход делает решение объяснимым и помогает заметить крайний случай до запуска. Это важно именно для темы «Вложенные циклы».

## 2. Основная идея

Вложенный цикл перебирает пары или тройки. Порядок индексов `i < j < k` одновременно исключает повторный подсчёт и не даёт использовать один элемент несколько раз. В уроке «Вложенные циклы» это основной рабочий приём.

```python
for i in range(3):
    for j in range(i + 1, 3):
        print(i, j)
```

## 3. Разбор по шагам

Начните с маленького входа, для которого ответ можно проверить вручную. На каждом шаге меняйте только те значения, которые действительно описывают состояние задачи. Если ответ выглядит неожиданно, не переписывайте программу сразу: выпишите состояние после первого, второго и третьего шага. Это важно именно для темы «Вложенные циклы».

```python
best = None
for value in [4, 1, 7]:
    if best is None or value < best:
        best = value
print(best)
```

## 4. Шаблон решения

1. Прочитайте условие и выделите входные данные.
2. Назовите переменную, список или таблицу, где будет храниться текущий результат.
3. Выполните один понятный шаг для каждого элемента или состояния.
4. Отдельно проверьте пустой, минимальный и пограничный случаи. Это важно именно для темы «Вложенные циклы».

## 5. Частые ошибки

Не смешивайте данные входа с ответом, который ещё строится. Не полагайтесь на случайный пример: для «Вложенные циклы» полезно отдельно проверить минимальный допустимый вход и случай, в котором нужного ответа нет. Если используется индекс, заранее договоритесь, с нуля или с единицы начинается нумерация. Это важно именно для темы «Вложенные циклы».
