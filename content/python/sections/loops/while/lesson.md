# Цикл while

После урока вы сможете повторять действия, пока условие истинно.

> **Фокус**
> - Нужно знать: условия, переменные и присваивание.
> - Нужно уметь: задавать начальное состояние, условие продолжения и изменение состояния.
> - Полезно знать: состояние должно приближать условие к ложному.

## Три части цикла

До `while` задают начальное состояние. Условие проверяется перед каждой итерацией. Внутри состояние должно изменяться.

```python
number = 1
while number <= 5:
    print(number)
    number += 1
```

## Когда число повторений заранее неизвестно

`while` удобен, когда остановка определяется текущим состоянием. После каждой итерации можно объяснить, что означает переменная.

```python
value = int(input())
while value > 0:
    print(value)
    value -= 1
print("стоп")
```

## Частые ошибки

Не забывайте менять переменную из условия. Проверяйте случай, когда условие ложно уже до первой итерации.
