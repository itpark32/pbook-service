## 1. Зачем нужен этот приём

Урок «Последовательности и ввод до стоп-сигнала» нужен, когда решение зависит не от угадывания ответа, а от ясного порядка действий. Сначала назовите данные, которые меняются на каждом шаге, затем сформулируйте проверку и только после этого пишите программу. Такой подход делает решение объяснимым и помогает заметить крайний случай до запуска. Это важно именно для темы «Последовательности и ввод до стоп-сигнала».

## 2. Основная идея

Программа получает данные через `input`, сохраняет их в переменных и показывает результат через `print`. Переменная нужна, когда введённое значение потребуется больше одного раза или должно получить понятное имя. В уроке «Последовательности и ввод до стоп-сигнала» это основной рабочий приём.

```python

print(name)
```

## 3. Разбор по шагам

Начните с маленького входа, для которого ответ можно проверить вручную. На каждом шаге меняйте только те значения, которые действительно описывают состояние задачи. Если ответ выглядит неожиданно, не переписывайте программу сразу: выпишите состояние после первого, второго и третьего шага. Это важно именно для темы «Последовательности и ввод до стоп-сигнала».


3. Выполните один понятный шаг для каждого элемента или состояния.
4. Отдельно проверьте пустой, минимальный и пограничный случаи. Это важно именно для темы «Последовательности и ввод до стоп-сигнала».

## 5. Частые ошибки

Не смешивайте данные входа с ответом, который ещё строится.
