## Основная идея

Программа получает данные через `input`, сохраняет их в переменных и показывает результат через `print`. Переменная нужна, когда введённое значение потребуется больше одного раза или должно получить понятное имя. В уроке «Последовательности и ввод до стоп-сигнала» это основной рабочий приём. В этой теме это относится к умению: обрабатывать поток значений и корректно работать со стоп-сигналом.

```python

```

## 3. Разбор по шагам

Стоп-сигнал проверяют до обновления ответа, если он не входит в последовательность. После каждого шага накопитель описывает только уже прочитанные данные. В этой теме это относится к умению: обрабатывать поток значений и корректно работать со стоп-сигналом.

```python
first = input()
second = input()
print(first + ' ' + second)
```

4. Отдельно проверьте пустой, минимальный и пограничный случаи. В этой теме это относится к умению: обрабатывать поток значений и корректно работать со стоп-сигналом.
