# Последовательности и ввод до стоп-сигнала

После урока вы сможете обрабатывать поток значений и корректно работать со стоп-сигналом.

Последовательность можно обрабатывать по одному числу, не сохраняя весь список.

Сначала определите формат входа, затем смысл каждого накопителя. Это отделяет чтение данных от условия задачи и помогает не включить служебное значение в ответ.

> **Фокус**
> - **Нужно знать:** два формата ввода — N чисел и ввод до стоп-значения.
> - **Нужно уметь:** совместить условие и накопитель.
> - **Полезно знать:** список не нужен, если к прошлым значениям не возвращаемся.
>
## 1. Сначала дано N

```python
n = int(input())
count = 0
total = 0

for _ in range(n):
    number = int(input())
    if number > 0 and number % 3 == 0:
        count += 1
        total += number

print(count, total)
```

## 2. До нуля

```python
count = 0
number = int(input())

while number != 0:
    if number < 0:
        count += 1
    number = int(input())

print(count)
```

Ноль управляет окончанием и не обрабатывается. Если нужно сравнивать соседей, храните предыдущее значение; если обращаться ко всем элементам позже — создайте список.

## 3. Соседние элементы в потоке

Для сравнения с предыдущим элементом весь список не нужен:

```python
previous = int(input())
count = 0
current = int(input())

while current != 0:
    if current > previous:
        count += 1
    previous = current
    current = int(input())

print(count)
```

Перед шагом `previous` хранит последний обработанный элемент, а `current` — новый. Первый элемент только задаёт предыдущий, поэтому сравнения начинаются со второго. Проверьте отдельно последовательность из одного числа.

## 4. Как спроектировать решение

1. Запишите, что завершает ввод.
2. Сформулируйте условие подходящего элемента.
3. Выберите накопители и начальные значения.
4. Решите, нужен ли предыдущий элемент или весь список.
5. Проверьте пустой набор подходящих данных.

## 5. Частые ошибки

- путать `for` для N элементов и `while` до признака;
- включать стоп-значение в результат;
- забывать следующий ввод;
- хранить большой список без необходимости.
