# Целочисленное деление и цифры

После урока вы сможете использовать // и % для работы с цифрами числа.

Целочисленное деление и остаток помогают исследовать делимость и доставать цифры числа.


> **Фокус**
> - **Нужно знать:** `27 // 10 == 2`, `27 % 10 == 7`.
> - **Нужно уметь:** проверить чётность и извлечь цифры.
> - **Полезно знать:** цикл позволяет обработать число любой длины.
>
## 1. Цифры справа налево

```python
number = 538
last = number % 10
tens = number // 10 % 10
hundreds = number // 100
```

Остаток от деления на 10 — последняя цифра. `number // 10` удаляет её. Число чётное, если `number % 2 == 0`, и делится на 7, если остаток равен нулю.

### Как устроено извлечение

| выражение | результат для 538 | что узнали |
|---|---:|---|
| `number % 10` | 8 | последняя цифра |
| `number // 10` | 53 | число без последней цифры |
| `number // 10 % 10` | 3 | цифра десятков |
| `number // 100` | 5 | цифра сотен |

Для цифры десятков сначала отбрасываем единицы, затем берём остаток от деления на 10. По той же схеме `number // 1000 % 10` извлечёт цифру тысяч.

Число делится на `d`, если `number % d == 0`. Последняя цифра сразу помогает проверить чётность и кратность 5. Но признак делимости на 3 через одну последнюю цифру проверить нельзя: понадобится сумма всех цифр.

## 2. Число произвольной длины

```python
number = 53842
digit_sum = 0

while number > 0:
    digit_sum += number % 10
    number //= 10

print(digit_sum)
```

На каждом шаге берём последнюю цифру и отбрасываем её. Для числа `0` сумму нужно обработать отдельно только если задача требует считать количество цифр.

| шаг | `number` до шага | цифра | сумма после шага |
|---:|---:|---:|---:|
| 1 | 53842 | 2 | 2 |
| 2 | 5384 | 4 | 6 |
| 3 | 538 | 8 | 14 |
| 4 | 53 | 3 | 17 |
| 5 | 5 | 5 | 22 |

Переменная `number` разрушается. Если исходное значение ещё понадобится, сохраните `copy = number`. Для отрицательного ввода часто удобно начать с `number = abs(number)`. По этому каркасу можно считать количество цифр, искать максимальную цифру или собирать число в обратном порядке.

## 3. Частые ошибки

- писать `number / 10` и получать дробь;
- проверять делимость как `number % d == d`;
- забывать менять `number` внутри `while`;
- терять исходное число: сохраните копию, если оно понадобится после цикла.
