## Основная идея

Остаток `% 10` выделяет последнюю цифру, а целочисленное деление `// 10` убирает её. Повторяя эти действия, можно разбирать число справа налево без строк. В уроке «Целочисленное деление и цифры» это основной рабочий приём. В этой теме это относится к умению: использовать // и % для работы с цифрами числа.

```python
number = int(input())
print(number % 10)
```
