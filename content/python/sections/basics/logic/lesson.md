# Сравнения и логика

После урока вы сможете составлять сравнения и логические выражения.

Логическое выражение отвечает «да» или «нет» и получает значение `True` либо `False`.

В программе такое выражение играет роль вопроса: «число подходит?», «индекс ещё внутри списка?», «пользователь ввёл допустимое значение?». Чем точнее вопрос переведён с русского языка на Python, тем проще условие и меньше случайных ошибок.

> **Фокус**
> - **Нужно знать:** сравнения, `and`, `or`, `not`.
> - **Нужно уметь:** переводить условие задачи в выражение.
> - **Полезно знать:** цепочка `10 <= x <= 20` читается как в математике.
>
## 1. Сравнения и связки

```python
number % 2 == 0 and number > 100
age < 14 or age > 18
not (x > 10)
10 <= x <= 20
```

`and` требует истинности обеих частей. `or` — хотя бы одной. `not` меняет истину на ложь. Скобки делают порядок явным.

| Запись | Смысл |
|---|---|
| `x == 5` | равно |
| `x != 5` | не равно |
| `a <= x <= b` | внутри отрезка |
| `x < a or x > b` | вне отрезка |

## 2. Перевод условия задачи

Не пытайтесь сразу печатать длинную строку кода. Сначала выделите простые утверждения. Например: «число двузначное и делится на 7, но не делится на 5».

1. Двузначное положительное: `10 <= number <= 99`.
2. Делится на 7: `number % 7 == 0`.
3. Не делится на 5: `number % 5 != 0`.

```python
fits = (10 <= number <= 99
        and number % 7 == 0
        and number % 5 != 0)
```

Промежуточная переменная `fits` не обязательна, но делает смысл видимым. Это особенно полезно при отладке длинного фильтра.

Следите за словами «строго», «не менее» и «не более»:

| фраза | Python |
|---|---|
| больше 10 | `x > 10` |
| не меньше 10 | `x >= 10` |
| от 10 до 20 включительно | `10 <= x <= 20` |
| вне отрезка | `x < 10 or x > 20` |

Отрицание всего условия требует скобок. `not (10 <= x <= 20)` также означает, что `x` находится вне отрезка.

## 3. Разбор

Для `number = 112`: условие `number % 2 == 0` истинно и `number > 100` истинно, значит всё выражение с `and` истинно. Для `99` вторая часть ложна — результат `False`.

Проверяйте выражение на заведомо подходящем, неподходящем и пограничном значениях. Для диапазона `[10; 20]` возьмите `15`, `7`, `10` и `20`: границы быстро обнаруживают путаницу между `<` и `<=`.

## 4. Частые ошибки

- `=` вместо `==`;
- путать «оба» (`and`) и «хотя бы один» (`or`);
- писать `x == 3 or 5` вместо `x == 3 or x == 5`;
- отрицать сложное условие без скобок.
