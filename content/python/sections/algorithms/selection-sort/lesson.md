# Простые сортировки

После урока вы сможете реализовывать сортировку выбором и понимать её шаги.

> **Фокус**
> - Нужно знать: списки, вложенные циклы и индексы.
> - Нужно уметь: строить отсортированный префикс, выбирая минимум из хвоста.
> - Полезно знать: после шага i элементы до i уже стоят на окончательных местах.

## Выбираем минимум хвоста

На позиции `i` должен оказаться минимальный элемент среди `i ... n-1`. Сначала найдите его индекс, потом обменяйте элементы.

```python
values = [5, 2, 4, 1]
for i in range(len(values)):
    min_index = i
    for j in range(i + 1, len(values)):
        if values[j] < values[min_index]:
            min_index = j
    values[i], values[min_index] = values[min_index], values[i]
print(values)
```

## Инвариант префикса

После первой итерации на позиции 0 находится минимум всего списка; после второй первые два элемента окончательны.

```python
values = [3, 1, 2]
i = 0
min_index = i
for j in range(i + 1, len(values)):
    if values[j] < values[min_index]:
        min_index = j
values[i], values[min_index] = values[min_index], values[i]
print(values)
```

## Частые ошибки

Не меняйте элементы при каждом сравнении: сначала найдите индекс минимума. Внутренний цикл начинается после готового префикса.
