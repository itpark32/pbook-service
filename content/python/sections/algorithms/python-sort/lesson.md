## 1. Зачем нужен этот приём

Урок «sort, sorted и key» нужен, когда решение зависит не от угадывания ответа, а от ясного порядка действий. Сначала назовите данные, которые меняются на каждом шаге, затем сформулируйте проверку и только после этого пишите программу. Такой подход делает решение объяснимым и помогает заметить крайний случай до запуска. Это важно именно для темы «sort, sorted и key».

## 2. Основная идея

`sorted` возвращает новый список, а `.sort()` меняет существующий. Параметр `key` отделяет правило сравнения от самих объектов и позволяет сортировать записи по нужному полю. В уроке «sort, sorted и key» это основной рабочий приём.

```python
print(sorted(['bob', 'ann']))
```

## 3. Разбор по шагам

Начните с маленького входа, для которого ответ можно проверить вручную. На каждом шаге меняйте только те значения, которые действительно описывают состояние задачи. Если ответ выглядит неожиданно, не переписывайте программу сразу: выпишите состояние после первого, второго и третьего шага. Это важно именно для темы «sort, sorted и key».

```python
records = [('ann', 9), ('bob', 7)]
print(sorted(records, key=lambda item: item[1]))
```

Не полагайтесь на случайный пример: для «sort, sorted и key» полезно отдельно проверить минимальный допустимый вход и случай, в котором нужного ответа нет.
