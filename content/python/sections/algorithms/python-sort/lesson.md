# sort, sorted и key

После урока вы сможете сортировать данные встроенными средствами и задавать ключ.

> **Фокус**
> - Нужно знать: списки, кортежи и функции.
> - Нужно уметь: различать `.sort()` и `sorted()` и задавать правило через `key`.
> - Полезно знать: `key` возвращает значение, по которому сравниваются элементы.

## Два способа сортировки

`sorted` создаёт новый список. `.sort()` меняет существующий список.

```python
values = [5, 2, 9, 1]
ordered = sorted(values)
print(values)
print(ordered)
```

## Сортировка по ключу

Если элемент состоит из нескольких частей, `key` задаёт поле или вычисляемый признак для сравнения.

```python
records = [("Анна", 15), ("Борис", 13), ("Вера", 14)]
records.sort(key=lambda item: item[1])
print(records)
```

## Частые ошибки

Не присваивайте результат `.sort()` как новый список. Если нужен исходный порядок, используйте `sorted`.
