# Двоичный поиск

После урока вы сможете искать значение в отсортированном массиве за логарифмическое время.

> **Фокус**
> - Нужно знать: отсортированный список, индексы и `while`.
> - Нужно уметь: сохранять диапазон возможного положения ответа и делить его пополам.
> - Полезно знать: алгоритм работает только когда порядок позволяет отбросить половину диапазона.

## Границы поиска

`left` и `right` задают диапазон, где ещё может находиться ответ. После сравнения диапазон уменьшается, но возможная позиция ответа не теряется.

```python
values = [2, 5, 8, 13, 21]
target = 13
left = 0
right = len(values) - 1
position = -1

while left <= right:
    middle = (left + right) // 2
    if values[middle] == target:
        position = middle
        break
    if values[middle] < target:
        left = middle + 1
    else:
        right = middle - 1

print(position)
```

## Как меняется диапазон

Если средний элемент меньше цели, вся левая часть вместе с `middle` уже не подходит. Если больше — не подходит правая часть.

```python
values = [1, 4, 7, 10, 15, 19]
target = 6
left = 0
right = len(values) - 1

while left <= right:
    middle = (left + right) // 2
    print(left, middle, right)
    if values[middle] < target:
        left = middle + 1
    else:
        right = middle - 1
```

## Частые ошибки

Не применяйте двоичный поиск к неотсортированным данным. Не оставляйте `middle` внутри нового диапазона после доказательства, что он не подходит.
