# Двоичный поиск

После урока вы сможете искать значение в отсортированном массиве за логарифмическое время.

> **Фокус**
> - Нужно знать: приёмы предыдущих уроков курса.
> - Нужно уметь: искать значение в отсортированном массиве за логарифмическое время.
> - Полезно знать: практику из урока «Двоичный поиск».

## 1. Зачем нужен этот приём

Урок «Двоичный поиск» нужен, когда решение зависит не от угадывания ответа, а от ясного порядка действий. Сначала назовите данные, которые меняются на каждом шаге, затем сформулируйте проверку и только после этого пишите программу. Такой подход делает решение объяснимым и помогает заметить крайний случай до запуска. Это важно именно для темы «Двоичный поиск».

## 2. Основная идея

Двоичный поиск работает только на отсортированных данных. На каждом шаге он отбрасывает половину диапазона, поэтому необходимо сохранять инвариант: ответ, если существует, остаётся между `left` и `right`. В уроке «Двоичный поиск» это основной рабочий приём.

```python
values = [1, 3, 5]
left, right = 0, 2
while left <= right:
    middle = (left + right) // 2
    if values[middle] < 5:
        left = middle + 1
    else:
        right = middle - 1
```

## 3. Разбор по шагам

Начните с маленького входа, для которого ответ можно проверить вручную. На каждом шаге меняйте только те значения, которые действительно описывают состояние задачи. Если ответ выглядит неожиданно, не переписывайте программу сразу: выпишите состояние после первого, второго и третьего шага. Это важно именно для темы «Двоичный поиск».

```python
values = [1, 3, 5]
print(5 in values)
```

## 4. Шаблон решения

1. Прочитайте условие и выделите входные данные.
2. Назовите переменную, список или таблицу, где будет храниться текущий результат.
3. Выполните один понятный шаг для каждого элемента или состояния.
4. Отдельно проверьте пустой, минимальный и пограничный случаи. Это важно именно для темы «Двоичный поиск».

## 5. Частые ошибки

Не смешивайте данные входа с ответом, который ещё строится. Не полагайтесь на случайный пример: для «Двоичный поиск» полезно отдельно проверить минимальный допустимый вход и случай, в котором нужного ответа нет. Если используется индекс, заранее договоритесь, с нуля или с единицы начинается нумерация. Это важно именно для темы «Двоичный поиск».
