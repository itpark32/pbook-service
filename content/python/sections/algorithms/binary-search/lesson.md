# Двоичный поиск

После урока вы сможете искать значение в отсортированном массиве за логарифмическое время.

> **Фокус**
> - Нужно знать: отсортированный список, индексы и `while`,
> - Нужно уметь: искать значение в отсортированном массиве за логарифмическое время.
> - Полезно знать: сначала выполните Guided 1, затем перенесите приём в Guided 2.

## 1. Зачем нужен этот приём

Здесь важно увидеть конкретный механизм, а не запомнить готовый ответ.

## Основная идея

Двоичный поиск работает только на отсортированных данных. На каждом шаге он отбрасывает половину диапазона, поэтому необходимо сохранять инвариант: ответ, если существует, остаётся между `left` и `right`. В уроке «Двоичный поиск» это основной рабочий приём. В этой теме это относится к умению: искать значение в отсортированном массиве за логарифмическое время.

```python
values = [1, 3, 5]
left, right = 0, 2
while left <= right:
    middle = (left + right) // 2
    if values[middle] < 5:
        left = middle + 1
    else:
        right = middle - 1
```

## 3. Разбор по шагам

После каждого сравнения искомое значение, если существует, остаётся в диапазоне [left, right]. middle вычисляют как середину текущего диапазона. В этой теме это относится к умению: искать значение в отсортированном массиве за логарифмическое время.

```python

print(5 in values)
```
