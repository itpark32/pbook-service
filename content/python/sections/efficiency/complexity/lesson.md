# Оценка сложности

После урока вы сможете оценивать число операций и выбирать подходящий алгоритм.

> **Фокус**
> - Нужно знать: циклы, вложенные циклы, поиск и сортировку.
> - Нужно уметь: связывать размер входа с количеством основных шагов.
> - Полезно знать: важен порядок роста, а не точное число инструкций Python.

## Один проход и квадратный перебор

Один цикл по n элементам даёт порядка n шагов. Два вложенных цикла могут дать порядка n² пар.

```python
values = [3, 7, 2, 9]
total = 0
for value in values:
    total += value
print(total)
```

## Ограничения подсказывают подход

Если n увеличить в 10 раз, `O(n)` станет примерно в 10 раз тяжелее, а `O(n²)` — примерно в 100.

```python
values = [3, 7, 2, 9]
pairs = 0
for i in range(len(values)):
    for j in range(len(values)):
        pairs += 1
print(pairs)
```

## Частые ошибки

Не судите по скорости на маленьком примере. Два последовательных цикла — не `O(n²)`, а `O(n)`.
