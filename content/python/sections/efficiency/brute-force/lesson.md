# Полный перебор

После урока вы сможете строить полный перебор и отсеивать неподходящие варианты.

Если вариантов немного, надёжный алгоритм может проверить каждый и оставить подходящие.

> **Фокус**
> - **Нужно уметь:** описать пространство вариантов и условие проверки.
>
```python
for a in range(10):
    for b in range(10):
        number = 10 * a + b
        if number >= 10 and number % 7 == 0:
            print(number)
```

Здесь 100 пар цифр. Проверка `number >= 10` исключает записи с ведущим нулём. Для четырёх цифр будет уже `10⁴` комбинаций; до запуска оцените объём. Уменьшайте диапазон и отбрасывайте невозможное как можно раньше.

## Четыре шага проектирования

1. Назовите все независимые варианты.
2. Задайте для каждого точный диапазон.
3. Постройте кандидат.
4. Проверьте ограничения и обновите ответ.

Такое описание помогает доказать полноту: каждый допустимый кандидат будет рассмотрен, а каждый выведенный кандидат проходит проверку.

```python
count = 0
for x in range(1, 10):
    for y in range(10):
        if x + y == 10 and (10 * x + y) % 4 == 0:
            count += 1
print(count)
```

Первая цифра сразу начинается с 1, поэтому отдельная проверка ведущего нуля не нужна.

## Оценка до запуска

Перемножьте размеры диапазонов. Пять десятичных цифр дают 100 000 комбинаций, десять — уже 10 миллиардов. Ограничения лучше отражать в диапазонах и проверять как можно раньше. Но оптимизация не должна исключать допустимые варианты: сначала объясните её математически.

> **Python+**
> `itertools.product` может перечислять декартово произведение, но не заменяет понимание вложенных циклов.
>
## Мини-практика

1. Подберите цифру для делимости. 2. Найдите пары `2x+y=11`. 3. Посчитайте трёхбуквенные слова по условию. 4. Найдите трёхзначные палиндромы. 5. Переберите пары элементов без повторов. 6. Оцените объём для восьми двоичных позиций.
