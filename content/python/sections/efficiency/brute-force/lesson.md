# Полный перебор

После урока вы сможете строить полный перебор и отсеивать неподходящие варианты.

> **Фокус**
> - Нужно знать: циклы, вложенные циклы и условия.
> - Нужно уметь: перечислять все варианты без пропусков и проверять каждый условием.
> - Полезно знать: перебор корректен, только если множество кандидатов покрыто целиком.

## Один параметр

Если диапазон небольшой, можно проверить каждый кандидат. Сначала определите границы, затем условие отбора.

```python
for x in range(1, 21):
    if x * x <= 80 and (x + 3) % 5 == 0:
        print(x)
```

## Несколько параметров

Для пары вариантов используют вложенные циклы. Ограничения применяйте как можно раньше.

```python
for a in range(1, 6):
    for b in range(1, 6):
        if a < b and a + b == 6:
            print(a, b)
```

## Частые ошибки

Не начинайте код до определения диапазона кандидатов. Следите за дублированием симметричных вариантов.
