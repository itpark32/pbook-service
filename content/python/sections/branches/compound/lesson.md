# Составные и вложенные условия

После урока вы сможете объединять и вкладывать условия без лишних ветвей.

> **Фокус**
> - Нужно знать: `if/elif/else`, `and`, `or`, `not`.
> - Нужно уметь: выбирать между составным условием, независимыми `if` и вложенной проверкой.
> - Полезно знать: два независимых `if` могут выполниться оба.

## Независимые проверки

Используйте два `if`, когда нужно проверить два независимых свойства. `if/elif` нужен, когда выбирается только один вариант.

```python
number = int(input())
if number > 0:
    print("положительное")
if number % 2 == 0:
    print("чётное")
```

## Вложенное условие уточняет случай

Если вторую проверку имеет смысл делать только после первой, поместите её внутрь соответствующей ветви.

```python
age = int(input())
has_ticket = input() == "да"
if age >= 14:
    if has_ticket:
        print("проходите")
    else:
        print("нужен билет")
else:
    print("слишком рано")
```

## Частые ошибки

Не заменяйте независимые проверки цепочкой `elif`. Не создавайте вложенность, если условие ясно выражается через `and`.
