## 1. Зачем нужен этот приём

## Основная идея

Цепочка `if/elif/else` делит значения на непересекающиеся диапазоны. Располагайте границы по порядку, иначе широкая ранняя проверка закроет более точную ветку. В уроке «elif и диапазоны» это основной рабочий приём. В этой теме это относится к умению: разбивать значения на несколько взаимоисключающих диапазонов.

```python
value = int(input())
if value < 0:
    print('low')
elif value < 10:
    print('middle')
else:
    print('high')
```
