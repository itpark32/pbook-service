# elif и диапазоны

> - Нужно уметь: разбивать значения на несколько взаимоисключающих диапазонов.
> - Полезно знать: практику из урока «elif и диапазоны».

## 1. Зачем нужен этот приём

Урок «elif и диапазоны» нужен, когда решение зависит не от угадывания ответа, а от ясного порядка действий. Сначала назовите данные, которые меняются на каждом шаге, затем сформулируйте проверку и только после этого пишите программу. Такой подход делает решение объяснимым и помогает заметить крайний случай до запуска. Это важно именно для темы «elif и диапазоны».

## 2. Основная идея

Цепочка `if/elif/else` делит значения на непересекающиеся диапазоны. Располагайте границы по порядку, иначе широкая ранняя проверка закроет более точную ветку. В уроке «elif и диапазоны» это основной рабочий приём.

```python
value = int(input())
if value < 0:
    print('low')
elif value < 10:
    print('middle')
else:
    print('high')
```

## 3. Разбор по шагам

Начните с маленького входа, для которого ответ можно проверить вручную. На каждом шаге меняйте только те значения, которые действительно описывают состояние задачи. Если ответ выглядит неожиданно, не переписывайте программу сразу: выпишите состояние после первого, второго и третьего шага. Это важно именно для темы «elif и диапазоны».

```python
value = int(input())
print(10 <= value <= 99)
```

## 4. Шаблон решения

1. Прочитайте условие и выделите входные данные.
2. Назовите переменную, список или таблицу, где будет храниться текущий результат.
3. Выполните один понятный шаг для каждого элемента или состояния.
4. Отдельно проверьте пустой, минимальный и пограничный случаи. Это важно именно для темы «elif и диапазоны».

## 5. Частые ошибки

Не смешивайте данные входа с ответом, который ещё строится. Не полагайтесь на случайный пример: для «elif и диапазоны» полезно отдельно проверить минимальный допустимый вход и случай, в котором нужного ответа нет. Если используется индекс, заранее договоритесь, с нуля или с единицы начинается нумерация. Это важно именно для темы «elif и диапазоны».
