# elif и диапазоны

После урока вы сможете разбивать значения на несколько взаимоисключающих диапазонов.

Программа не всегда должна выполнять одни и те же команды. Например, положительную температуру и мороз нужно описать по-разному, а скидку следует применять только при выполнении условия. Для такого выбора в Python используется команда `if`.

> **Фокус**
> - **Нужно знать:** как работают `if`, `elif`, `else` и отступы.
> - **Нужно уметь:** составить условие, расположить ветви в правильном порядке и выбрать между несколькими `if` и цепочкой `elif`.
> - **Полезно знать:** сложное условие часто можно упростить с помощью логических операторов и проверки границ.
>
## 3. Несколько вариантов: `if`, `elif`, `else`

Для трёх и более взаимоисключающих вариантов используют цепочку `elif`. Python проверяет условия сверху вниз и останавливается на первой подходящей ветви.

```python
temperature = int(input())

if temperature < 0:
    print("мороз")
elif temperature < 15:
    print("прохладно")
elif temperature < 25:
    print("тепло")
else:
    print("жарко")
```

Проследим выполнение для разных значений.

| Температура | `< 0` | `< 15` | `< 25` | Результат |
|---:|:---:|:---:|:---:|---|
| `-4` | да | не проверяется | не проверяется | мороз |
| `10` | нет | да | не проверяется | прохладно |
| `20` | нет | нет | да | тепло |
| `30` | нет | нет | нет | жарко |

В ветви `elif temperature < 15` не требуется дополнительно писать `temperature >= 0`. До неё программа доходит только тогда, когда первая проверка уже оказалась ложной.

Порядок условий важен. Если сначала написать `temperature < 25`, то значения `-4`, `10` и `20` попадут в одну и ту же ветвь. Более узкие границы в такой задаче должны идти раньше широких.

## 6. Типовой алгоритм: размер скидки

Пусть до 1000 рублей скидки нет, от 1000 до 4999 рублей действует скидка 5%, а начиная с 5000 рублей — 10%.

```python
price = int(input())

if price >= 5000:
    discount = 10
elif price >= 1000:
    discount = 5
else:
    discount = 0

final_price = price * (100 - discount) / 100
print(final_price)
```

Проверка начинается с самой большой границы. При цене `6000` программа сразу выбирает скидку 10%. При цене `3000` первая проверка ложна, а вторая истинна. Значения меньше `1000` попадают в `else`.

> **Проверяйте граничные значения**
> Для этой программы полезно протестировать `999`, `1000`, `4999` и `5000`. Ошибки в условиях чаще всего обнаруживаются именно на границах диапазонов.
>
## 7. Частые ошибки

### Присваивание вместо сравнения

```python
# Ошибка
if number = 10:
    print("десять")
```

Один знак `=` присваивает значение. Для сравнения нужны два знака: `number == 10`.

### Неправильные отступы

```python
# Ошибка: вторая строка оказалась вне условия
if score >= 60:
    print("зачёт")
print("работа принята")
```

Код синтаксически допустим, но вторая строка выполняется при любом результате. Сначала определите, какие команды должны относиться к ветви, и только потом расставляйте отступы.

### Потерянная граница

Условие `score > 60` не включает значение `60`. Если зачёт начинается с 60 баллов, нужно написать `score >= 60`.

### Неверный порядок `elif`

Сначала проверяйте условие, которое точнее отделяет нужный диапазон. После написания цепочки подберите по одному тесту для каждой ветви и для каждой границы.

## 8. Мини-практика

1. **Знак числа.** Введите целое число и выведите `положительное`, `отрицательное` или `ноль`.
2. **Максимум.** Введите два числа и найдите большее без `max`. Отдельно проверьте случай равных чисел.
3. **Возрастная группа.** До 7 лет — дошкольник, от 7 до 17 — школьник, начиная с 18 — взрослый.
4. **Делимость.** Для числа выведите все подходящие сообщения: `делится на 2`, `делится на 3`, `делится на 5`. Одно число может получить несколько сообщений.
5. **Координатная четверть.** По ненулевым координатам `x` и `y` определите номер четверти.
6. **Доставка.** При заказе от 3000 рублей доставка бесплатная. Иначе она стоит 300 рублей. Выведите итоговую стоимость заказа.

Для каждой программы заранее выпишите граничные тесты, а затем сравните ожидаемый результат с фактическим.
