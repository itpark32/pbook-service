## 1. Зачем нужен этот приём

Урок «Ошибки и отладка» нужен, когда решение зависит не от угадывания ответа, а от ясного порядка действий. Сначала назовите данные, которые меняются на каждом шаге, затем сформулируйте проверку и только после этого пишите программу. Такой подход делает решение объяснимым и помогает заметить крайний случай до запуска. Это важно именно для темы «Ошибки и отладка».

## 2. Основная идея

Отладка начинается с классификации ошибки: синтаксис не даёт запустить программу, исполнение падает на конкретной операции, логика выдаёт неверный ответ. Маленькая трассировка переменных показывает место расхождения с ожиданием. В уроке «Ошибки и отладка» это основной рабочий приём.

```python
total = 0
for value in [3, 5, 2]:
    total += value
print(total)
```

## 3. Разбор по шагам

Начните с маленького входа, для которого ответ можно проверить вручную. На каждом шаге меняйте только те значения, которые действительно описывают состояние задачи. Если ответ выглядит неожиданно, не переписывайте программу сразу: выпишите состояние после первого, второго и третьего шага. Это важно именно для темы «Ошибки и отладка».

```python
number = int(input())
if number % 2 == 0:
    print('even')
else:
    print('odd')
```

## 4. Шаблон решения

1. Прочитайте условие и выделите входные данные.
2. Назовите переменную, список или таблицу, где будет храниться текущий результат.
3. Выполните один понятный шаг для каждого элемента или состояния.
4. Отдельно проверьте пустой, минимальный и пограничный случаи. Это важно именно для темы «Ошибки и отладка».

## 5. Частые ошибки

Не смешивайте данные входа с ответом, который ещё строится. Не полагайтесь на случайный пример: для «Ошибки и отладка» полезно отдельно проверить минимальный допустимый вход и случай, в котором нужного ответа нет. Если используется индекс, заранее договоритесь, с нуля или с единицы начинается нумерация. Это важно именно для темы «Ошибки и отладка».
