# if и else

После урока вы сможете выбирать ровно один из двух вариантов с if и else.

> **Фокус**
> - Нужно знать: приёмы предыдущих уроков курса.
> - Нужно уметь: выбирать ровно один из двух вариантов с if и else.
> - Полезно знать: практику из урока «if и else».

## 1. Зачем нужен этот приём

Урок «if и else» нужен, когда решение зависит не от угадывания ответа, а от ясного порядка действий. Сначала назовите данные, которые меняются на каждом шаге, затем сформулируйте проверку и только после этого пишите программу. Такой подход делает решение объяснимым и помогает заметить крайний случай до запуска. Это важно именно для темы «if и else».

## 2. Основная идея

Условие выбирает одну ветку. В `if/else` каждая строка результата должна быть достижима ровно в одном из двух случаев; это удобно проверять на граничном значении. В уроке «if и else» это основной рабочий приём.

```python
number = int(input())
if number >= 0:
    print('PLUS')
else:
    print('MINUS')
```

## 3. Разбор по шагам

Начните с маленького входа, для которого ответ можно проверить вручную. На каждом шаге меняйте только те значения, которые действительно описывают состояние задачи. Если ответ выглядит неожиданно, не переписывайте программу сразу: выпишите состояние после первого, второго и третьего шага. Это важно именно для темы «if и else».

```python
score = int(input())
if score >= 90:
    print('A')
elif score >= 60:
    print('B')
else:
    print('C')
```

## 4. Шаблон решения

1. Прочитайте условие и выделите входные данные.
2. Назовите переменную, список или таблицу, где будет храниться текущий результат.
3. Выполните один понятный шаг для каждого элемента или состояния.
4. Отдельно проверьте пустой, минимальный и пограничный случаи. Это важно именно для темы «if и else».

## 5. Частые ошибки

Не смешивайте данные входа с ответом, который ещё строится. Не полагайтесь на случайный пример: для «if и else» полезно отдельно проверить минимальный допустимый вход и случай, в котором нужного ответа нет. Если используется индекс, заранее договоритесь, с нуля или с единицы начинается нумерация. Это важно именно для темы «if и else».
