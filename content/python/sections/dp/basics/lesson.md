## 1. Зачем нужен этот приём

Урок «Основы динамического программирования» нужен, когда решение зависит не от угадывания ответа, а от ясного порядка действий. Сначала назовите данные, которые меняются на каждом шаге, затем сформулируйте проверку и только после этого пишите программу. Такой подход делает решение объяснимым и помогает заметить крайний случай до запуска. Это важно именно для темы «Основы динамического программирования».

## 2. Основная идея

Динамика хранит ответы для меньших состояний. Сначала формулируют смысл `dp[i]`, затем базу и переход, после чего выбирают порядок заполнения, при котором нужные ответы уже посчитаны. В уроке «Основы динамического программирования» это основной рабочий приём.

```python
ways = [1, 0, 0, 0]
for i in range(3):
    ways[i + 1] += ways[i]
print(ways)
```

## 3. Разбор по шагам

Начните с маленького входа, для которого ответ можно проверить вручную. На каждом шаге меняйте только те значения, которые действительно описывают состояние задачи. Если ответ выглядит неожиданно, не переписывайте программу сразу: выпишите состояние после первого, второго и третьего шага. Это важно именно для темы «Основы динамического программирования».

```python
dp = [0, 3, 4, 8]
print(dp[-1])
```

## 5. Частые ошибки

Не смешивайте данные входа с ответом, который ещё строится. Не полагайтесь на случайный пример: для «Основы динамического программирования» полезно отдельно проверить минимальный допустимый вход и случай, в котором нужного ответа нет. Если используется индекс, заранее договоритесь, с нуля или с единицы начинается нумерация. Это важно именно для темы «Основы динамического программирования».
