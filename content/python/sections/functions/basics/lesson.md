## 1. Зачем нужен этот приём

Урок «Функции: параметры и return» нужен, когда решение зависит не от угадывания ответа, а от ясного порядка действий. Сначала назовите данные, которые меняются на каждом шаге, затем сформулируйте проверку и только после этого пишите программу. Такой подход делает решение объяснимым и помогает заметить крайний случай до запуска. Это важно именно для темы «Функции: параметры и return».

## 2. Основная идея

Функция выделяет один законченный шаг с параметрами и результатом `return`. Локальные переменные не должны незаметно менять внешнее состояние, поэтому декомпозиция начинается с чёткого контракта функции. В уроке «Функции: параметры и return» это основной рабочий приём.

```python
def square(number):
    return number * number

print(square(4))
```

## 3. Разбор по шагам

Начните с маленького входа, для которого ответ можно проверить вручную. На каждом шаге меняйте только те значения, которые действительно описывают состояние задачи. Если ответ выглядит неожиданно, не переписывайте программу сразу: выпишите состояние после первого, второго и третьего шага. Это важно именно для темы «Функции: параметры и return».

```python
def larger(left, right):
    return left if left > right else right
```

## 4. Шаблон решения

1. Прочитайте условие и выделите входные данные.
2. Назовите переменную, список или таблицу, где будет храниться текущий результат.
3. Выполните один понятный шаг для каждого элемента или состояния.
4. Отдельно проверьте пустой, минимальный и пограничный случаи. Это важно именно для темы «Функции: параметры и return».

## 5. Частые ошибки

Не смешивайте данные входа с ответом, который ещё строится. Не полагайтесь на случайный пример: для «Функции: параметры и return» полезно отдельно проверить минимальный допустимый вход и случай, в котором нужного ответа нет. Если используется индекс, заранее договоритесь, с нуля или с единицы начинается нумерация. Это важно именно для темы «Функции: параметры и return».
