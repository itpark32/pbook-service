# Строки: символы и индексы

После урока вы сможете перебирать символы строки и безопасно использовать индексы.

> **Фокус**
> - Нужно знать: циклы и переменные.
> - Нужно уметь: получать символ по индексу и обходить строку слева направо.
> - Полезно знать: индексы строки начинаются с нуля.

## Строка — последовательность символов

`len(text)` даёт количество символов. Первый символ имеет индекс `0`, последний — `len(text) - 1`.

```python
text = "python"
print(len(text))
print(text[0])
print(text[len(text) - 1])
```

## Перебор символов

Если индекс не нужен, удобнее перебирать сами символы. Знакомые идеи счётчика и условия применяются к строке без изменений.

```python
text = input()
count = 0
for char in text:
    if char == "a":
        count += 1
print(count)
```

## Частые ошибки

Не обращайтесь к `text[len(text)]`: такого индекса нет. Пробел тоже является символом.
