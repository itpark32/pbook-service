# Методы строк и срезы

После урока вы сможете преобразовывать строки методами и срезами.

Методы возвращают новую строку: `lower`, `upper`, `strip`, `find`, `count`, `replace`, `split`; `join` собирает строку, `isdigit` и `isalpha` проверяют состав.
> **Фокус**
> - **Нужно знать:** `text[start:stop:step]`.
> - **Нужно уметь:** нормализовать ввод и делить текст на слова.
> - **Полезно знать:** срез не включает правую границу.
```python
text = "  Python для школы  ".strip().lower()
words = text.split()
print(" | ".join(words))
word = "algorithm"
print(word[:4], word[4:], word[::2], word[::-1])
```
Палиндром проверяется как `word == word[::-1]`. `find` возвращает `-1`, если фрагмент не найден. Не забывайте присвоить результат метода: строка сама не меняется.

## Сначала задача, потом метод

Методы удобно объединять в конвейер: убрать пробелы по краям, привести регистр, затем разделить на слова. Внутренние пробелы `strip()` не удаляет.

```python
raw = "  Маша, Петя, Оля  "
names = raw.strip().split(",")
for name in names:
    print(name.strip())
```

`split` превращает одну строку в список частей, `join` выполняет обратную операцию. Разделитель у `join` стоит слева: `", ".join(names)`.

## Срез как диапазон индексов

Срез `text[start:stop:step]` следует тем же правилам, что `range`: начало включается, конец нет. Пропущенные границы означают начало или конец строки. В отличие от отдельного индекса, слишком широкая граница среза не вызывает ошибку.

| срез | смысл |
|---|---|
| `text[:3]` | первые три символа |
| `text[3:]` | от индекса 3 до конца |
| `text[::2]` | каждый второй символ |
| `text[::-1]` | строка наоборот |

`find` подходит, когда нужна позиция. Для простой проверки наличия яснее писать `part in text`. Если `find` вернул `-1`, использовать это значение как обычный индекс нельзя.
