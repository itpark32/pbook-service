# Системы счисления

После урока вы сможете переводить целые числа между позиционными системами.

> **Фокус**
> - Нужно знать: целочисленное деление, остаток и строки.
> - Нужно уметь: раскладывать число по степеням основания и собирать запись через остатки.
> - Полезно знать: в системе основания b каждая позиция имеет вес степени b.

## В десятичное число

Идя слева направо, текущий результат умножают на основание и добавляют очередную цифру.

```python
digits = "1011"
base = 2
value = 0
for char in digits:
    value = value * base + int(char)
print(value)
```

## Из десятичного числа

Остатки от деления на основание появляются справа налево, поэтому их добавляют в начало результата.

```python
number = 13
base = 2
result = ""
while number > 0:
    digit = number % base
    result = str(digit) + result
    number //= base
print(result)
```

## Частые ошибки

Не читайте запись из другой системы как десятичную. Отдельно обработайте число 0 при обратном переводе.
