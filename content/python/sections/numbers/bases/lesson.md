# Системы счисления

После урока вы сможете переводить целые числа между позиционными системами.

Система счисления задаёт основание и допустимые цифры. Python умеет читать записи и переводить число обратно.

> **Фокус**
> - **Нужно знать:** `int(text, base)`, `bin`, `oct`, `hex`.
> - **Нужно уметь:** вручную переводить из десятичной системы в основание 2–9.
>
```python
print(int("101101", 2))  # 45
print(bin(45))            # 0b101101
```

```python
number = 45
base = 2
result = ""
while number > 0:
    result = str(number % base) + result
    number //= base
print(result)
```

Остатки появляются справа налево, поэтому новая цифра добавляется в начало. Для исходного нуля результат должен быть `"0"`.

## Из записи в число

Запись `101101₂` означает `1·2⁵ + 0·2⁴ + 1·2³ + 1·2² + 0·2 + 1 = 45`. Удобный ручной алгоритм читает цифры слева направо: умножить накопленный результат на основание и прибавить новую цифру.

```python
value = 0
for digit in "101101":
    value = value * 2 + int(digit)
```

После каждого шага `value` равен значению уже прочитанного префикса.

## Проверяем цифры и префиксы

В системе с основанием `base` допустимы цифры от 0 до `base - 1`. Для оснований выше 10 появляются буквы, поэтому учебную функцию проще сначала ограничить основаниями 2–9. `bin`, `oct`, `hex` возвращают строки с префиксами `0b`, `0o`, `0x`; при подсчёте цифр учитывайте префикс или используйте срез `[2:]`.

Для перевода из десятичной системы сохраняйте исходное число, если оно понадобится: цикл деления доведёт рабочую копию до нуля.
