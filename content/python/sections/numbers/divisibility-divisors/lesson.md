## Основная идея

Делитель оставляет нулевой остаток. Для НОД алгоритм Евклида заменяет пару чисел на второе число и остаток; это уменьшает вход и сохраняет общий делитель. В уроке «Делимость и делители» это основной рабочий приём. В этой теме это относится к умению: проверять делимость и эффективно перечислять делители.

```python
number = int(input())
for divisor in range(1, number + 1):
    if number % divisor == 0:
        print(divisor)
```
