# Делимость и делители

После урока вы сможете проверять делимость и эффективно перечислять делители.

> **Фокус**
> - Нужно знать: `%`, циклы и условия.
> - Нужно уметь: проверять делитель и использовать парность делителей.
> - Полезно знать: если d делит n, парный делитель равен n // d.

## Проверка делимости

`n % d == 0` означает, что остатка нет и `d` является делителем `n`.

```python
n = 84
d = 7
if n % d == 0:
    print("делится")
else:
    print("не делится")
```

## Делители образуют пары

Достаточно перебирать `d`, пока `d * d <= n`. Второй делитель получается как `n // d`.

```python
n = 36
d = 1
while d * d <= n:
    if n % d == 0:
        print(d)
        if d != n // d:
            print(n // d)
    d += 1
```

## Частые ошибки

Не печатайте квадратный корень дважды. Никогда не проверяйте деление на ноль.
