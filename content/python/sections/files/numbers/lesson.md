# Числовые данные в файлах

После урока вы сможете обрабатывать числа из файла потоково.

> **Фокус**
> - Нужно знать: файлы, `int` и накопители.
> - Нужно уметь: читать число за числом и поддерживать сумму, количество или экстремум.
> - Полезно знать: накопитель описывает уже прочитанные числа.

## Число нужно преобразовать

Строка из файла остаётся текстом. Перед арифметикой преобразуйте её в `int`.

```python
total = 0
with open("numbers.txt", "r", encoding="utf-8") as file:
    for line in file:
        value = int(line.strip())
        total += value
print(total)
```

## Экстремум без списка

Большой файл не обязательно хранить целиком. Текущий ответ можно обновлять по мере чтения.

```python
best = None
with open("numbers.txt", "r", encoding="utf-8") as file:
    for line in file:
        value = int(line.strip())
        if best is None or value > best:
            best = value
print(best)
```

## Частые ошибки

Не вызывайте `int` для пустой строки, если формат её допускает. Не загружайте весь файл без необходимости.

## Проверьте себя

1. Почему `line` сначала строка?
2. Что хранит `total`?
3. Зачем максимуму начальное `None`?
