# Линейный поиск

После урока вы сможете находить элемент и его индекс линейным проходом.

Линейный поиск проверяет элементы по порядку и работает даже без сортировки.
> **Фокус**
> - **Нужно знать:** флаг, индекс `-1`, досрочный `break`.
```python
target = 7
position = -1
for i in range(len(numbers)):
    if numbers[i] == target:
        position = i
        break
print(position)
```
`-1` означает «не найдено». Без `break` можно собрать все позиции. После ручного алгоритма: `target in numbers`; `.index(target)` требует заранее знать, что значение существует.

## Что именно требуется найти

До кода уточните результат: факт наличия, первый индекс, последний индекс, количество или все позиции. Для факта достаточно флага `found`; для первого индекса нужен `break`; для последнего перебор продолжают и обновляют позицию.

```python
positions = []
for i in range(len(numbers)):
    if numbers[i] == target:
        positions.append(i)
```

Этот вариант сохраняет все найденные позиции. Пустой список естественно означает отсутствие совпадений.

## Почему поиск линейный

В худшем случае проверяется каждый элемент: искомое значение находится в конце или отсутствует. Сортировка не нужна, поэтому метод надёжен для любого порядка. Если список уже отсортирован и запросов много, позже можно применить бинарный поиск.

Проверьте случаи: значение в начале, в конце, встречается несколько раз и отсутствует. Они показывают, правильно ли выбран `break` и значение «не найдено».

1. Найдите первое отрицательное. 2. Соберите все индексы нулей. 3. Проверьте наличие оценки 2. 4. Найдите последний индекс максимума. 5. Найдите первое число больше среднего. 6. Реализуйте собственную функцию поиска.
