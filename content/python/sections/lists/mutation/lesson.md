# Изменение списков

После урока вы сможете изменять элементы и осознанно применять методы списка.

> **Фокус**
> - Нужно знать: создание списка и индексы.
> - Нужно уметь: заменять элемент, добавлять и удалять значения.
> - Полезно знать: в отличие от строки, список изменяем.

## Замена и добавление

Элемент можно заменить по индексу. `append` добавляет значение в конец и меняет тот же список.

```python
values = [3, 5, 7]
values[1] = 10
values.append(12)
print(values)
```

## Удаление зависит от задачи

`pop()` удаляет и возвращает последний элемент. `remove(value)` удаляет первое совпадение по значению.

```python
items = ["a", "b", "c"]
last = items.pop()
items.remove("a")
print(last)
print(items)
```

## Частые ошибки

Не путайте индекс и значение: `pop(1)` удаляет позицию, `remove(1)` ищет значение 1. Не меняйте длину списка внутри прохода без причины.
