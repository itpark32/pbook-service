# Обработка списков

После урока вы сможете фильтровать, преобразовывать и агрегировать элементы списка.

По элементам перебирают для вычислений, по индексам — когда важна позиция или изменение.
> **Фокус**
> - **Нужно уметь:** считать, суммировать и строить новый список обычным циклом.
```python
positive = []
for number in numbers:
    if number > 0:
        positive.append(number)

for i in range(len(numbers)):
    numbers[i] *= 2
```
Сумму, минимум и максимум сначала реализуйте накопителями. В обычном коде после этого допустимы `sum`, `min`, `max`.

## Три результата одного прохода

Цикл может считать значение, изменять исходный список или строить новый — важно не смешивать цели. `append` добавляет элемент в конец нового списка. Изменение `numbers[i]` меняет исходный список, и это должно быть намеренно.

```python
squares_of_even = []
for number in numbers:
    if number % 2 == 0:
        squares_of_even.append(number ** 2)
```

Порядок действий совпадает с условием: проверить, преобразовать, добавить. После каждого шага результат содержит квадраты всех подходящих уже просмотренных элементов.

Если удалять элементы из списка во время прямого перебора, позиции сдвигаются и часть данных может быть пропущена. Безопаснее построить новый список или перебрать копию.

## Выбираем вид цикла

Перебор по значениям нужен для суммы, фильтра и проверок. Индексы нужны для замены на месте и обращения к соседям. `enumerate(numbers)` даёт одновременно индекс и значение, когда нужны оба. Сначала напишите прозрачный цикл, затем при желании сократите его.
> **Python+**
> `[x for x in numbers if x > 0]` — краткая запись, но она не заменяет понимание цикла.
