## 1. Зачем нужен этот приём

Здесь важно увидеть конкретный механизм, а не запомнить готовый ответ.

## Основная идея

Список смежности хранит для каждой вершины её соседей. Такое представление удобно для разреженных графов и отделяет данные графа от алгоритма, который будет их обходить. В уроке «Обходы DFS и BFS» это основной рабочий приём. В этой теме это относится к умению: обходить достижимые вершины в глубину и ширину.

```python
graph = [[] for _ in range(3)]
for left, right in [(0, 1), (1, 2)]:
    graph[left].append(right)
    graph[right].append(left)
print(graph)
```

## 3. Разбор по шагам

Список смежности хранит соседей каждой вершины. Для обхода нужно отдельное множество посещённых вершин: оно не даёт ходить по циклу бесконечно. В этой теме это относится к умению: обходить достижимые вершины в глубину и ширину.

```python
graph = [[1], [0, 2], [1]]
print(len(graph[1]))
```
