## 1. Зачем нужен этот приём

Урок «Представление графа» нужен, когда решение зависит не от угадывания ответа, а от ясного порядка действий. Сначала назовите данные, которые меняются на каждом шаге, затем сформулируйте проверку и только после этого пишите программу. Такой подход делает решение объяснимым и помогает заметить крайний случай до запуска. Это важно именно для темы «Представление графа».

## 2. Основная идея

Список смежности хранит для каждой вершины её соседей. Такое представление удобно для разреженных графов и отделяет данные графа от алгоритма, который будет их обходить. В уроке «Представление графа» это основной рабочий приём.

```python
graph = [[] for _ in range(3)]
for left, right in [(0, 1), (1, 2)]:
    graph[left].append(right)
    graph[right].append(left)
print(graph)
```

## 3. Разбор по шагам

Начните с маленького входа, для которого ответ можно проверить вручную. На каждом шаге меняйте только те значения, которые действительно описывают состояние задачи. Если ответ выглядит неожиданно, не переписывайте программу сразу: выпишите состояние после первого, второго и третьего шага. Это важно именно для темы «Представление графа».

```python
graph = [[1], [0, 2], [1]]
print(len(graph[1]))
```

## 4. Шаблон решения

1. Прочитайте условие и выделите входные данные.
2. Назовите переменную, список или таблицу, где будет храниться текущий результат.
3. Выполните один понятный шаг для каждого элемента или состояния.
4. Отдельно проверьте пустой, минимальный и пограничный случаи. Это важно именно для темы «Представление графа».

## 5. Частые ошибки

Не смешивайте данные входа с ответом, который ещё строится. Не полагайтесь на случайный пример: для «Представление графа» полезно отдельно проверить минимальный допустимый вход и случай, в котором нужного ответа нет. Если используется индекс, заранее договоритесь, с нуля или с единицы начинается нумерация. Это важно именно для темы «Представление графа».
