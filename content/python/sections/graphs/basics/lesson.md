# Представление графа

После урока вы сможете хранить граф списками смежности.

> **Фокус**
> - Нужно знать: списки, двумерные структуры и циклы.
> - Нужно уметь: превращать набор рёбер в список соседей каждой вершины.
> - Полезно знать: для неориентированного ребра связь добавляется в обе стороны.

## Список смежности

Для каждой вершины хранится список её соседей. Это удобно для графов с относительно небольшим числом рёбер.

```python
n = 4
graph = [[] for _ in range(n)]
edges = [(0, 1), (0, 2), (2, 3)]
for a, b in edges:
    graph[a].append(b)
    graph[b].append(a)
print(graph)
```

## Ориентированное ребро

Если связь имеет направление `a → b`, вершина b добавляется к соседям a, но обратная связь не появляется автоматически.

```python
n = 3
graph = [[] for _ in range(n)]
edges = [(0, 1), (1, 2)]
for a, b in edges:
    graph[a].append(b)
print(graph)
```

## Частые ошибки

Не добавляйте обратное ребро в ориентированном графе. Согласуйте нумерацию вершин со входными данными.
