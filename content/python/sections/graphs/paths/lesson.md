## 2. Основная идея

В невзвешенном графе BFS идёт слоями от старта. Первая встреча вершины даёт минимальное число рёбер до неё, а массив родителей позволяет затем восстановить сам путь. В уроке «Пути и расстояния в невзвешенном графе» это основной рабочий приём.

```python
graph = [[1], [0, 2], [1]]
distance = [-1, -1, -1]
distance[0] = 0
queue = [0]
for vertex in queue:
    for neighbour in graph[vertex]:
        if distance[neighbour] == -1:
            distance[neighbour] = distance[vertex] + 1
            queue.append(neighbour)
print(distance)
```
