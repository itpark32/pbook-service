# Стиль текстов PBook

Пишем для школьников 13–17 лет: точно, спокойно и без снисходительности. Новый термин объясняем при первом появлении, а не прячем за общими словами.

- Один элемент интерфейса — одна мысль; не дублируем её в кнопке, подсказке и модальном окне.
- Урок: «не начат», «в процессе», «пройден». Задача: «не решена», «решена».
- Практикум: «N из M задач решено».
- В пользовательском интерфейсе говорим «приглашение», не «инвайт».
- Ошибка сообщает следующий шаг, загрузка — текущее действие, пустой экран — доступное действие пользователя.
