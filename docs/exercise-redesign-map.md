## Правила банка

- У каждого урока ровно три задания: два guided и checkpoint.
- У каждого задания есть не менее трёх прогонов reference solution и не менее двух предметных подсказок.
- Практикумы не выбирают задания из общего пула: порядок, сложность и смысл каждого пункта заданы явно.
- Запреты на `max`, `sorted`, `.sort()` и рекурсию применяются только там, где их поддерживает структурная проверка рантайма.
