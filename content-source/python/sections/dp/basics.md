## 1. Зачем нужен этот приём

Здесь важно увидеть конкретный механизм, а не запомнить готовый ответ.

## Основная идея

Динамика хранит ответы для меньших состояний. Сначала формулируют смысл `dp[i]`, затем базу и переход, после чего выбирают порядок заполнения, при котором нужные ответы уже посчитаны. В уроке «Основы динамического программирования» это основной рабочий приём. В этой теме это относится к умению: выделять состояние, переход и базовые значения.

```python
ways = [1, 0, 0, 0]
for i in range(3):
    ways[i + 1] += ways[i]
print(ways)
```

## 3. Разбор по шагам

Сначала формулируют смысл dp[i], затем базовые значения, переход и порядок заполнения. Ответ лежит в явно названной ячейке таблицы. В этой теме это относится к умению: выделять состояние, переход и базовые значения.

```python
dp = [0, 3, 4, 8]
print(dp[-1])
```
