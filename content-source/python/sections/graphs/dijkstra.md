# Алгоритм Дейкстры

После урока вы сможете находить кратчайшие расстояния во взвешенном графе с неотрицательными рёбрами.

> **Фокус**

> - Нужно уметь: релаксировать рёбра и выбирать вершину с наименьшей дистанцией через `heapq`.

## 1. Когда BFS уже недостаточно

BFS находит путь с наименьшим числом рёбер. Если у рёбер разная стоимость, такой путь может быть дороже другого. Алгоритм Дейкстры находит минимальную суммарную стоимость, но требует, чтобы веса были неотрицательными. В этой теме это относится к умению: находить кратчайшие расстояния во взвешенном графе с неотрицательными рёбрами.

## 2. Релаксация и куча

Храним `distance[v]` — лучшую найденную цену пути до вершины `v`. При просмотре ребра `v → to` с весом `weight` получаем кандидата `distance[v] + weight`. Если он лучше старой цены, обновляем ответ и кладём новую пару в кучу. В этой теме это относится к умению: находить кратчайшие расстояния во взвешенном графе с неотрицательными рёбрами.

```python
import heapq

graph = [[(1, 4), (2, 1)], [(0, 4), (2, 2)], [(0, 1), (1, 2)]]
distance = [None, None, None]
distance[0] = 0
heap = [(0, 0)]

while heap:
    current, vertex = heapq.heappop(heap)
    if current != distance[vertex]:
        continue
    for neighbour, weight in graph[vertex]:
        candidate = current + weight
        if distance[neighbour] is None or candidate < distance[neighbour]:
            distance[neighbour] = candidate
            heapq.heappush(heap, (candidate, neighbour))
```

## 3. Почему запись в куче может устареть

До извлечения вершины из кучи её расстояние могут улучшить через другой путь. Старую пару удалять не нужно: при извлечении достаточно сравнить её цену с текущим `distance[vertex]`. Если они не равны, эта запись больше не полезна. В этой теме это относится к умению: находить кратчайшие расстояния во взвешенном графе с неотрицательными рёбрами.

```python
parent = [None, 2, 0]
path = []
vertex = 1
while vertex is not None:
    path.append(vertex)
    vertex = parent[vertex]
print(path[::-1])  # [0, 2, 1]
```

## 5. Частые ошибки

Не заменяйте Дейкстру BFS: BFS оптимизирует число рёбер, а не стоимость. Не используйте алгоритм при отрицательных весах. Не забывайте проверку устаревшей записи: без неё программа будет выполнять лишнюю работу и сложнее проверять её рассуждение.
