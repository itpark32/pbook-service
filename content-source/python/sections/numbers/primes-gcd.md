## 1. Зачем нужен этот приём

Урок «Простые числа и НОД» нужен, когда решение зависит не от угадывания ответа, а от ясного порядка действий. Сначала назовите данные, которые меняются на каждом шаге, затем сформулируйте проверку и только после этого пишите программу. Такой подход делает решение объяснимым и помогает заметить крайний случай до запуска. Это важно именно для темы «Простые числа и НОД».

## 2. Основная идея

Число меньше двух не является простым. Чтобы проверить делимость, достаточно пробовать делители до квадратного корня: если есть большой делитель, ему соответствует малый. В уроке «Простые числа и НОД» это основной рабочий приём.

```python
number = int(input())
print(number >= 2)
```

## 3. Разбор по шагам

Начните с маленького входа, для которого ответ можно проверить вручную. На каждом шаге меняйте только те значения, которые действительно описывают состояние задачи. Если ответ выглядит неожиданно, не переписывайте программу сразу: выпишите состояние после первого, второго и третьего шага. Это важно именно для темы «Простые числа и НОД».

```python
a, b = 48, 18
while b:
    a, b = b, a % b
print(a)
```

4. Отдельно проверьте пустой, минимальный и пограничный случаи. Это важно именно для темы «Простые числа и НОД».

## 5. Частые ошибки

Не смешивайте данные входа с ответом, который ещё строится. Не полагайтесь на случайный пример: для «Простые числа и НОД» полезно отдельно проверить минимальный допустимый вход и случай, в котором нужного ответа нет. Если используется индекс, заранее договоритесь, с нуля или с единицы начинается нумерация. Это важно именно для темы «Простые числа и НОД».
