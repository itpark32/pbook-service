## 1. Зачем нужен этот приём

Здесь важно увидеть конкретный механизм, а не запомнить готовый ответ.

## Основная идея

Условие выбирает одну ветку. В `if/else` каждая строка результата должна быть достижима ровно в одном из двух случаев; это удобно проверять на граничном значении. В уроке «if и else» это основной рабочий приём. В этой теме это относится к умению: выбирать ровно один из двух вариантов с if и else.

```python
number = int(input())
if number >= 0:
    print('PLUS')
else:
    print('MINUS')
```
