## 1. Зачем нужен этот приём

## Основная идея

Оценка сложности описывает, как число шагов растёт с размером входа. Один цикл обычно даёт линейный рост, два вложенных — квадратичный; эту оценку делают до запуска на больших данных. В уроке «Оценка сложности» это основной рабочий приём. В этой теме это относится к умению: оценивать число операций и выбирать подходящий алгоритм.

```python
for value in range(10):
    print(value)
```

    for right in range(4):
