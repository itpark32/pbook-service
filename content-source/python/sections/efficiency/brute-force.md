## 1. Зачем нужен этот приём

Урок «Полный перебор» нужен, когда решение зависит не от угадывания ответа, а от ясного порядка действий. Сначала назовите данные, которые меняются на каждом шаге, затем сформулируйте проверку и только после этого пишите программу. Такой подход делает решение объяснимым и помогает заметить крайний случай до запуска. Это важно именно для темы «Полный перебор».

## 2. Основная идея

Полный перебор перечисляет все допустимые варианты и проверяет каждый. Его сила — простая корректность, а ограничение — рост числа вариантов; порядок индексов помогает не повторять одинаковые комбинации. В уроке «Полный перебор» это основной рабочий приём.

```python
for left in range(3):
    for right in range(left + 1, 3):
        print(left, right)
```

## 3. Разбор по шагам

Начните с маленького входа, для которого ответ можно проверить вручную. На каждом шаге меняйте только те значения, которые действительно описывают состояние задачи. Если ответ выглядит неожиданно, не переписывайте программу сразу: выпишите состояние после первого, второго и третьего шага. Это важно именно для темы «Полный перебор».

```python
best = None
for value in range(20):
    if value % 3 == 0:
        best = value
print(best)
```

## 4. Шаблон решения

1. Прочитайте условие и выделите входные данные.
2. Назовите переменную, список или таблицу, где будет храниться текущий результат.
3. Выполните один понятный шаг для каждого элемента или состояния.
4. Отдельно проверьте пустой, минимальный и пограничный случаи. Это важно именно для темы «Полный перебор».

## 5. Частые ошибки

Не смешивайте данные входа с ответом, который ещё строится. Не полагайтесь на случайный пример: для «Полный перебор» полезно отдельно проверить минимальный допустимый вход и случай, в котором нужного ответа нет. Если используется индекс, заранее договоритесь, с нуля или с единицы начинается нумерация. Это важно именно для темы «Полный перебор».
