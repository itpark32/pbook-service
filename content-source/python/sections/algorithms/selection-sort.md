## 1. Зачем нужен этот приём

Урок «Простые сортировки» нужен, когда решение зависит не от угадывания ответа, а от ясного порядка действий. Сначала назовите данные, которые меняются на каждом шаге, затем сформулируйте проверку и только после этого пишите программу. Такой подход делает решение объяснимым и помогает заметить крайний случай до запуска. Это важно именно для темы «Простые сортировки».

## 2. Основная идея

Сортировка выбором на каждом шаге ищет минимальный элемент неотсортированного хвоста и ставит его на следующую позицию. Она медленнее встроенной сортировки, но хорошо показывает идею инварианта отсортированного префикса. В уроке «Простые сортировки» это основной рабочий приём.

```python
values = [4, 1, 3]
for i in range(len(values)):
    for j in range(i + 1, len(values)):
        if values[j] < values[i]:
            values[i], values[j] = values[j], values[i]
print(values)
```

## 3. Разбор по шагам

Начните с маленького входа, для которого ответ можно проверить вручную. На каждом шаге меняйте только те значения, которые действительно описывают состояние задачи. Если ответ выглядит неожиданно, не переписывайте программу сразу: выпишите состояние после первого, второго и третьего шага. Это важно именно для темы «Простые сортировки».

```python
values = [4, 1, 3]
print(min(values))
```

## 4. Шаблон решения

1. Прочитайте условие и выделите входные данные.
2. Назовите переменную, список или таблицу, где будет храниться текущий результат.
3. Выполните один понятный шаг для каждого элемента или состояния.
4. Отдельно проверьте пустой, минимальный и пограничный случаи. Это важно именно для темы «Простые сортировки».

## 5. Частые ошибки

Не смешивайте данные входа с ответом, который ещё строится. Не полагайтесь на случайный пример: для «Простые сортировки» полезно отдельно проверить минимальный допустимый вход и случай, в котором нужного ответа нет. Если используется индекс, заранее договоритесь, с нуля или с единицы начинается нумерация. Это важно именно для темы «Простые сортировки».
