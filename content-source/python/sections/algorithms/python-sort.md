## Основная идея

`sorted` возвращает новый список, а `.sort()` меняет существующий. Параметр `key` отделяет правило сравнения от самих объектов и позволяет сортировать записи по нужному полю. В уроке «sort, sorted и key» это основной рабочий приём. В этой теме это относится к умению: сортировать данные встроенными средствами и задавать ключ.

```python
print(sorted(['bob', 'ann']))
```

print(sorted(records, key=lambda item: item[1]))
