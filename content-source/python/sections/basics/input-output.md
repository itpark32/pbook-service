## 1. Зачем нужен этот приём

Здесь важно увидеть конкретный механизм, а не запомнить готовый ответ.

## Основная идея

Программа получает данные через `input`, сохраняет их в переменных и показывает результат через `print`. Переменная нужна, когда введённое значение потребуется больше одного раза или должно получить понятное имя. В уроке «Ввод, вывод и переменные» это основной рабочий приём. В этой теме это относится к умению: читать данные, сохранять их в переменных и выводить результат.

```python
name = input()
print(name)
```
