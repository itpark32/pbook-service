## 1. Зачем нужен этот приём

Урок «Целочисленное деление и цифры» нужен, когда решение зависит не от угадывания ответа, а от ясного порядка действий. Сначала назовите данные, которые меняются на каждом шаге, затем сформулируйте проверку и только после этого пишите программу. Такой подход делает решение объяснимым и помогает заметить крайний случай до запуска. Это важно именно для темы «Целочисленное деление и цифры».

## 2. Основная идея

Остаток `% 10` выделяет последнюю цифру, а целочисленное деление `// 10` убирает её. Повторяя эти действия, можно разбирать число справа налево без строк. В уроке «Целочисленное деление и цифры» это основной рабочий приём.

```python
number = int(input())
print(number % 10)
```

## 3. Разбор по шагам

Начните с маленького входа, для которого ответ можно проверить вручную. На каждом шаге меняйте только те значения, которые действительно описывают состояние задачи. Если ответ выглядит неожиданно, не переписывайте программу сразу: выпишите состояние после первого, второго и третьего шага. Это важно именно для темы «Целочисленное деление и цифры».

```python
number = int(input())
print(number // 10 % 10)
```

4. Отдельно проверьте пустой, минимальный и пограничный случаи. Это важно именно для темы «Целочисленное деление и цифры».

## 5. Частые ошибки

Не смешивайте данные входа с ответом, который ещё строится. Не полагайтесь на случайный пример: для «Целочисленное деление и цифры» полезно отдельно проверить минимальный допустимый вход и случай, в котором нужного ответа нет.
