## 1. Зачем нужен этот приём

Урок «Типы и арифметика» нужен, когда решение зависит не от угадывания ответа, а от ясного порядка действий. Сначала назовите данные, которые меняются на каждом шаге, затем сформулируйте проверку и только после этого пишите программу. Такой подход делает решение объяснимым и помогает заметить крайний случай до запуска. Это важно именно для темы «Типы и арифметика».

## 2. Основная идея

Тип числа выбирают по смыслу результата: `int` для целых предметов и `float` для величин с дробной частью. Скобки в выражении показывают порядок вычислений и делают формулу проверяемой. В уроке «Типы и арифметика» это основной рабочий приём.

```python
price = int(input())
count = int(input())
print(price * count)
```

## 3. Разбор по шагам

Начните с маленького входа, для которого ответ можно проверить вручную. На каждом шаге меняйте только те значения, которые действительно описывают состояние задачи. Если ответ выглядит неожиданно, не переписывайте программу сразу: выпишите состояние после первого, второго и третьего шага. Это важно именно для темы «Типы и арифметика».

```python

b = float(input())
print((a + b) / 2)
```
