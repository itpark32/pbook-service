# Двумерные списки

После урока вы сможете создавать матрицы и обходить строки и столбцы.

> **Фокус**
> - Нужно знать: списки и вложенные циклы.
> - Нужно уметь: обращаться к элементу по номеру строки и столбца.
> - Полезно знать: `matrix[row][column]` сначала выбирает строку, затем элемент.

## Матрица — список строк

Каждая строка сама является списком. У элемента две координаты: номер строки и столбца.

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6]
]
print(matrix[0][2])
print(matrix[1][0])
```

## Полный обход

Внешний цикл перебирает строки, внутренний — элементы строки. Такой обход посещает каждую клетку один раз.

```python
matrix = [[1, 2], [3, 4], [5, 6]]
total = 0
for row in matrix:
    for value in row:
        total += value
print(total)
```

## Частые ошибки

Не меняйте местами строку и столбец. Если строки разной длины, ориентируйтесь на `len(row)`.
