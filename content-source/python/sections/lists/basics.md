# Создание списка, ввод и индексы

После урока вы сможете создавать списки, читать элементы и обращаться по индексам.

> **Фокус**
> - Нужно знать: строки, циклы и индексы.
> - Нужно уметь: хранить несколько значений в одном объекте и безопасно читать элементы.
> - Полезно знать: индексы списка начинаются с нуля.

## Список хранит последовательность значений

Литерал списка записывается в квадратных скобках. `len(values)` возвращает число элементов.

```python
values = [10, 20, 30, 40]
print(len(values))
print(values[0])
print(values[-1])
```

## Ввод нескольких чисел

Строку можно разбить по пробелам через `.split()`, затем каждую часть преобразовать в число обычным циклом.

```python
parts = input().split()
numbers = []
for part in parts:
    numbers.append(int(part))
print(numbers)
```

## Частые ошибки

Не обращайтесь к индексу за пределами списка. Результат `.split()` остаётся строками до явного преобразования.
