# Соседи, пары и тройки

После урока вы сможете обрабатывать соседние элементы без выхода за границы.

> **Фокус**
> - Нужно знать: списки, индексы и `range`.
> - Нужно уметь: выбирать безопасные границы цикла для пар и троек.
> - Полезно знать: если используется `values[i + 1]`, последний допустимый i меньше последнего индекса.

## Соседние пары

Для пары `values[i]` и `values[i + 1]` индекс `i` идёт только до предпоследнего элемента.

```python
values = [2, 5, 4, 8]
count = 0
for i in range(len(values) - 1):
    if values[i] < values[i + 1]:
        count += 1
print(count)
```

## Тройки

Для `i - 1`, `i`, `i + 1` перебирайте только внутренние позиции.

```python
values = [1, 5, 2, 7, 3]
for i in range(1, len(values) - 1):
    if values[i] > values[i - 1] and values[i] > values[i + 1]:
        print(i)
```

## Частые ошибки

Не используйте полный `range(len(values))`, если обращаетесь к следующему элементу. Проверяйте минимальную допустимую длину.
