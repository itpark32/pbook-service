# Чтение и запись файлов

После урока вы сможете безопасно читать и записывать текстовые файлы.

> **Фокус**
> - Нужно знать: строки, циклы и функции.
> - Нужно уметь: открывать текстовый файл через `with` и различать чтение и запись.
> - Полезно знать: `with` закрывает файл после выхода из блока.

## Чтение текста

Режим `r` используется для чтения. Строки файла можно обрабатывать по одной.

```python
with open("input.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip())
```

## Запись текста

Режим `w` записывает файл заново. Метод `write` не добавляет перевод строки автоматически.

```python
with open("output.txt", "w", encoding="utf-8") as file:
    file.write("первая строка\n")
    file.write("вторая строка\n")
```

## Частые ошибки

Не путайте `r` и `w`: запись в режиме `w` заменяет прежнее содержимое. Учитывайте перевод строки.
