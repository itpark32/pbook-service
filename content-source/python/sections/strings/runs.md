## 1. Зачем нужен этот приём

Урок «Состояние и серии символов» нужен, когда решение зависит не от угадывания ответа, а от ясного порядка действий. Сначала назовите данные, которые меняются на каждом шаге, затем сформулируйте проверку и только после этого пишите программу. Такой подход делает решение объяснимым и помогает заметить крайний случай до запуска. Это важно именно для темы «Состояние и серии символов».

## 2. Основная идея

Программа получает данные через `input`, сохраняет их в переменных и показывает результат через `print`. Переменная нужна, когда введённое значение потребуется больше одного раза или должно получить понятное имя. В уроке «Состояние и серии символов» это основной рабочий приём.

```python

```

## 3. Разбор по шагам

Начните с маленького входа, для которого ответ можно проверить вручную. На каждом шаге меняйте только те значения, которые действительно описывают состояние задачи. Если ответ выглядит неожиданно, не переписывайте программу сразу: выпишите состояние после первого, второго и третьего шага. Это важно именно для темы «Состояние и серии символов».

## 5. Частые ошибки

Не полагайтесь на случайный пример: для «Состояние и серии символов» полезно отдельно проверить минимальный допустимый вход и случай, в котором нужного ответа нет.
