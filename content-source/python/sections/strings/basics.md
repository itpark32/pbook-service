## 1. Зачем нужен этот приём

Урок «Строки: символы и индексы» нужен, когда решение зависит не от угадывания ответа, а от ясного порядка действий. ## 2. Основная идея

Строка — упорядоченная последовательность символов. Индексы, срезы и проход `for char in text` позволяют решить задачу, не превращая строку в набор несвязанных значений. В уроке «Строки: символы и индексы» это основной рабочий приём.

```python

```

## 3. Разбор по шагам

Начните с маленького входа, для которого ответ можно проверить вручную. На каждом шаге меняйте только те значения, которые действительно описывают состояние задачи. Если ответ выглядит неожиданно, не переписывайте программу сразу: выпишите состояние после первого, второго и третьего шага. Это важно именно для темы «Строки: символы и индексы».

```python
text = input()
print(text[::-1])
```
