# Словари и частоты

После урока вы сможете связывать ключи со значениями и строить таблицы частот.

> **Фокус**
> - Нужно знать: циклы, строки и коллекции.
> - Нужно уметь: создавать словарь и вручную обновлять значение по ключу.
> - Полезно знать: частотный словарь хранит число уже встреченных элементов для каждого ключа.

## Ключ ведёт к значению

Словарь удобен, когда данные получают не по позиции, а по имени ключа.

```python
ages = {"Анна": 14, "Борис": 15}
print(ages["Анна"])
ages["Вера"] = 13
print(ages)
```

## Таблица частот

При встрече элемента увеличьте его счётчик. Для нового ключа сначала создайте нулевое значение.

```python
text = "banana"
frequency = {}
for char in text:
    if char not in frequency:
        frequency[char] = 0
    frequency[char] += 1
print(frequency)
```

## Частые ошибки

Не обращайтесь к `data[key]`, пока не уверены, что ключ есть. Не путайте ключ и значение.
