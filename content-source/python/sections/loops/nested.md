## Основная идея

Вложенный цикл перебирает пары или тройки. Порядок индексов `i < j < k` одновременно исключает повторный подсчёт и не даёт использовать один элемент несколько раз. В уроке «Вложенные циклы» это основной рабочий приём. В этой теме это относится к умению: строить перебор пар и таблиц вложенными циклами.

```python
for i in range(3):
    for j in range(i + 1, 3):
        print(i, j)
```
