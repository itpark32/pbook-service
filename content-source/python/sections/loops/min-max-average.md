## 1. Зачем нужен этот приём

Здесь важно увидеть конкретный механизм, а не запомнить готовый ответ.

## Основная идея

Программа получает данные через `input`, сохраняет их в переменных и показывает результат через `print`. Переменная нужна, когда введённое значение потребуется больше одного раза или должно получить понятное имя. В уроке «Минимум, максимум и среднее» это основной рабочий приём. В этой теме это относится к умению: находить экстремумы и среднее без хранения всей последовательности.

```python
name = input()
print(name)
```

## 3. Разбор по шагам

После обработки первых i чисел счётчик хранит количество подходящих, сумма — сумму просмотренных значений, а произведение — их произведение. Для суммы стартуют с 0, для произведения — с 1. В этой теме это относится к умению: находить экстремумы и среднее без хранения всей последовательности.

```python
first = input()
second = input()
print(first + ' ' + second)
```
