# Минимум, максимум и среднее

После урока вы сможете находить экстремумы и среднее без хранения всей последовательности.

> **Фокус**
> - Нужно знать: циклы, счётчик и сумму.
> - Нужно уметь: обновлять текущий минимум/максимум и безопасно вычислять среднее.
> - Полезно знать: для непустой последовательности честное начальное значение экстремума — первый элемент.

## Текущий экстремум

После обработки первых элементов `maximum` должен быть максимумом именно среди них. Обновляйте его только при большем значении.

```python
numbers = [7, -2, 5, 11, 3]
maximum = numbers[0]
for value in numbers:
    if value > maximum:
        maximum = value
print(maximum)
```

## Среднее требует сумму и количество

Для среднего по условию накапливайте только подходящие значения. Перед делением убедитесь, что хотя бы одно значение подошло.

```python
numbers = [4, -1, 8, 0]
total = 0
count = 0
for value in numbers:
    if value > 0:
        total += value
        count += 1
if count > 0:
    print(total / count)
```

## Частые ошибки

Не начинайте максимум с 0, если все числа могут быть отрицательными. Не делите на нулевой `count`.
