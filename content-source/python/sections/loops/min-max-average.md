## 1. Зачем нужен этот приём

Урок «Минимум, максимум и среднее» нужен, когда решение зависит не от угадывания ответа, а от ясного порядка действий. Сначала назовите данные, которые меняются на каждом шаге, затем сформулируйте проверку и только после этого пишите программу. Такой подход делает решение объяснимым и помогает заметить крайний случай до запуска. Это важно именно для темы «Минимум, максимум и среднее».

## 2. Основная идея

Программа получает данные через `input`, сохраняет их в переменных и показывает результат через `print`. Переменная нужна, когда введённое значение потребуется больше одного раза или должно получить понятное имя. В уроке «Минимум, максимум и среднее» это основной рабочий приём.

```python
name = input()
print(name)
```

## 3. Разбор по шагам

Начните с маленького входа, для которого ответ можно проверить вручную. На каждом шаге меняйте только те значения, которые действительно описывают состояние задачи. Если ответ выглядит неожиданно, не переписывайте программу сразу: выпишите состояние после первого, второго и третьего шага. Это важно именно для темы «Минимум, максимум и среднее».

```python

second = input()
print(first + ' ' + second)
```

1. Прочитайте условие и выделите входные данные.
2. Назовите переменную, список или таблицу, где будет храниться текущий результат.
3. Выполните один понятный шаг для каждого элемента или состояния.
4. Отдельно проверьте пустой, минимальный и пограничный случаи. Это важно именно для темы «Минимум, максимум и среднее».

## 5. Частые ошибки

Не смешивайте данные входа с ответом, который ещё строится. Не полагайтесь на случайный пример: для «Минимум, максимум и среднее» полезно отдельно проверить минимальный допустимый вход и случай, в котором нужного ответа нет. Если используется индекс, заранее договоритесь, с нуля или с единицы начинается нумерация. Это важно именно для темы «Минимум, максимум и среднее».
