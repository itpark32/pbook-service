## 1. Зачем нужен этот приём

Здесь важно увидеть конкретный механизм, а не запомнить готовый ответ.

## Основная идея

Цикл нужен, когда один и тот же шаг повторяется для разных состояний. У `while` важно изменение условия завершения, у `for` — ясная последовательность значений; накопитель, счётчик и экстремум обновляются внутри тела цикла. В уроке «Цикл for и range» это основной рабочий приём. В этой теме это относится к умению: перебирать известный диапазон значений.

```python
total = 0
for value in range(1, 6):
    total += value
print(total)
```

## 3. Разбор по шагам

Сначала назовите, что хранит каждая ключевая переменная, и проверьте её значение на небольшом входе. Пример ниже показывает именно рабочий механизм этой темы. В этой теме это относится к умению: перебирать известный диапазон значений.

```python
current = 1
while current <= 3:
    print(current)
    current += 1
```
