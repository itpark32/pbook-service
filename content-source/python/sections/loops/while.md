## 1. Зачем нужен этот приём

Урок «Цикл while» нужен, когда решение зависит не от угадывания ответа, а от ясного порядка действий. Сначала назовите данные, которые меняются на каждом шаге, затем сформулируйте проверку и только после этого пишите программу. Такой подход делает решение объяснимым и помогает заметить крайний случай до запуска. Это важно именно для темы «Цикл while».

## 2. Основная идея

Цикл нужен, когда один и тот же шаг повторяется для разных состояний. У `while` важно изменение условия завершения, у `for` — ясная последовательность значений; накопитель, счётчик и экстремум обновляются внутри тела цикла. В уроке «Цикл while» это основной рабочий приём.

```python
total = 0
for value in range(1, 6):
    total += value
print(total)
```

## 3. Разбор по шагам

Начните с маленького входа, для которого ответ можно проверить вручную. На каждом шаге меняйте только те значения, которые действительно описывают состояние задачи. Если ответ выглядит неожиданно, не переписывайте программу сразу: выпишите состояние после первого, второго и третьего шага. Это важно именно для темы «Цикл while».

```python
current = 1
while current <= 3:
    print(current)
    current += 1
```

## 4. Шаблон решения

1. Прочитайте условие и выделите входные данные.
2. Назовите переменную, список или таблицу, где будет храниться текущий результат.
3. Выполните один понятный шаг для каждого элемента или состояния.
4. Отдельно проверьте пустой, минимальный и пограничный случаи. Это важно именно для темы «Цикл while».

## 5. Частые ошибки

Не смешивайте данные входа с ответом, который ещё строится. Не полагайтесь на случайный пример: для «Цикл while» полезно отдельно проверить минимальный допустимый вход и случай, в котором нужного ответа нет. Если используется индекс, заранее договоритесь, с нуля или с единицы начинается нумерация. Это важно именно для темы «Цикл while».
