# Трассировка программ

После урока вы сможете пошагово определять значения переменных и результат программы.

> **Фокус**
> - Нужно знать: условия и циклы.
> - Нужно уметь: фиксировать состояние после каждой значимой строки.
> - Полезно знать: таблица трассировки помогает проверить алгоритм до запуска.

## Записываем изменения

Для цикла сделайте столбцы для шага и переменных, которые меняются. Каждая строка таблицы соответствует одному проходу.

```python
total = 0
for value in range(1, 4):
    total += value
    print(value, total)
```

## Условие меняет путь выполнения

При трассировке отмечайте результат условия: он определяет, какие строки выполнятся.

```python
x = 5
if x > 3:
    x = x * 2
else:
    x = x - 2
print(x)
```

## Частые ошибки

Не перескакивайте через итерации «в уме». Если переменная меняется несколько раз, записывайте каждое новое состояние.
