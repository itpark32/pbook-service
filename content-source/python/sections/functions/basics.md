# Функции: параметры и return

После урока вы сможете объявлять функции, передавать аргументы и возвращать результат.

> **Фокус**
> - Нужно знать: переменные, условия и циклы.
> - Нужно уметь: выделять повторяемое вычисление в функцию с понятным контрактом.
> - Полезно знать: `return` возвращает значение и завершает текущий вызов.

## Параметры — вход функции

Параметры получают значения при вызове. Хорошая функция решает одну понятную подзадачу.

```python
def rectangle_area(width, height):
    return width * height

area = rectangle_area(4, 7)
print(area)
```

## return и print — не одно и то же

`print` показывает текст, а `return` отдаёт результат программе. Возвращённое значение можно использовать дальше.

```python
def is_even(number):
    return number % 2 == 0

print(is_even(8))
print(is_even(5))
```

## Частые ошибки

Не забывайте вызвать функцию после определения. Не заменяйте `return` на `print`, если результат нужен дальше.
