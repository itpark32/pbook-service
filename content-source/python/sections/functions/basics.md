## Основная идея

Функция выделяет один законченный шаг с параметрами и результатом `return`. Локальные переменные не должны незаметно менять внешнее состояние, поэтому декомпозиция начинается с чёткого контракта функции. В уроке «Функции: параметры и return» это основной рабочий приём. В этой теме это относится к умению: объявлять функции, передавать аргументы и возвращать результат.

```python
def square(number):
    return number * number

print(square(4))
```
