# Практикум 2. Циклы

Выбирайте между `for`, `while`, счётчиком, накопителем и текущим экстремумом.

## Что здесь проверяется

Повторение действий и состояние после каждого обработанного значения.

## Как работать

Перед кодом назовите начальное значение ответа и что оно означает после каждого шага.

## Если застряли
