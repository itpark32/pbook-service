# Сравнения и логика

После урока вы сможете составлять сравнения и логические выражения.

> **Фокус**
> - Нужно знать: числовые и строковые значения.
> - Нужно уметь: получать `True`/`False` и объединять условия через `and`, `or`, `not`.
> - Полезно знать: сравнение само является выражением типа `bool`.

## Сравнение даёт логическое значение

Операторы `==`, `!=`, `<`, `<=`, `>` и `>=` отвечают на вопрос о двух значениях. Результат можно сохранить или вывести.

```python
age = int(input())
adult = age >= 18
print(adult)
```

## Несколько требований

`and` требует истинности обеих частей, `or` — хотя бы одной, `not` меняет логическое значение на противоположное.

```python
x = int(input())
inside = x >= 10 and x <= 20
outside = x < 10 or x > 20
print(inside)
print(outside)
```

## Частые ошибки

Не путайте `=` и `==`. Для диапазона проверьте, включены ли его границы.
