# Ввод, вывод и переменные

После урока вы сможете читать данные, сохранять их в переменных и выводить результат.

> **Фокус**
> - Нужно знать: `input()` читает строку, переменная хранит значение, `print()` выводит результат.
> - Нужно уметь: сохранять введённые данные и использовать их в следующих командах.
> - Полезно знать: присваивание `=` записывает новое значение в переменную и не означает математическое равенство.

## Данные проходят через программу по шагам

Программа выполняет команды сверху вниз. `input()` останавливает выполнение и ждёт ввод пользователя. Полученное значение можно сохранить в переменную, а затем использовать дальше.

```python
name = input()
print("Привет,", name)
```

Сначала `input()` возвращает введённый текст. Затем этот текст попадает в переменную `name`. Последняя строка использует уже сохранённое значение.

Переменную можно представить как имя, которое указывает на текущее значение. Если выполнить новое присваивание, старое значение заменится.

```python
score = 5
score = 7
print(score)
```

Программа выведет `7`, потому что второе присваивание изменило значение `score`.

## `input()` возвращает строку

Даже если пользователь вводит цифры, результат `input()` имеет тип `str`. Преобразование к числу понадобится в следующем уроке. Пока важно различать сам ввод и значение, которое хранится после него.

Хорошие имена переменных помогают понять смысл программы: `age`, `price`, `student_name` понятнее, чем `a`, `b`, `x`, если задача не требует коротких обозначений.

## Частые ошибки

- использовать переменную до того, как ей присвоили значение;
- путать `=` и `==`;
- ожидать, что `input()` автоматически вернёт число;
- давать переменным имена, не связанные со смыслом данных;
- писать `print("name")`, когда нужно вывести значение `name`.
