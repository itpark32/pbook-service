# Типы и арифметика

После урока вы сможете выбирать числовой тип и составлять арифметические выражения.

> **Фокус**
> - Нужно знать: строки, переменные и `input()`.
> - Нужно уметь: преобразовывать ввод в `int` или `float` и вычислять выражения.
> - Полезно знать: `/` возвращает результат обычного деления.

## Строка и число — разные данные

`input()` даёт строку. Для арифметики строку явно преобразуют в число. `int` подходит для целых, `float` — для значений с дробной частью.

```python
age = int(input())
next_age = age + 1
print(next_age)
```

## Порядок операций

Python сначала выполняет степень, затем умножение и деление, затем сложение и вычитание. Скобки делают нужный порядок явным.

```python
price = float(input())
count = int(input())
total = price * count
print(total)
```

## Частые ошибки

Не складывайте числовой ввод до преобразования: строки соединятся как текст. Не используйте `int`, если возможна дробная часть.
