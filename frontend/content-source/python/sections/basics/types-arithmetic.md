# Типы и арифметика

После урока вы сможете выбирать числовой тип и составлять арифметические выражения.

> **Фокус**
> - Нужно знать: `int`, `float`, `str`, арифметические операции и приоритет действий.
> - Нужно уметь: преобразовывать строковый ввод к числу до вычислений.
> - Полезно знать: тип значения определяет, какие операции над ним имеют смысл.

## Строка и число — разные данные

`input()` возвращает строку. Для арифметики строку обычно нужно преобразовать в число.

```python
age = int(input())
next_age = age + 1
print(next_age)
```

Здесь цепочка такая: `input()` получает текст, `int(...)` превращает его в целое число, затем выполняется сложение.

Если нужны дробные значения, используют `float`.

```python
price = float(input())
count = int(input())
total = price * count
print(total)
```

`int` подходит для целых значений, например количества предметов. `float` используют, когда допустима дробная часть.

## Арифметические выражения

Основные операции:

- `+` — сложение;
- `-` — вычитание;
- `*` — умножение;
- `/` — обычное деление;
- `**` — возведение в степень.

Умножение и деление выполняются раньше сложения и вычитания. Если порядок должен быть другим, используйте скобки.

```python
result = (10 + 2) * 3
print(result)
```

Без скобок выражение `10 + 2 * 3` дало бы другой результат.

## Тип результата тоже важен

Операция `/` возвращает дробное число даже тогда, когда деление выполняется без остатка. Целочисленное деление `//` и остаток `%` будут подробно разобраны отдельно.

Не преобразовывайте результат в `int` только ради удаления дробной части: такое преобразование меняет данные и должно соответствовать условию задачи.

## Частые ошибки

- складывать результат `input()` с числом без `int` или `float`;
- использовать `int`, когда в условии возможна дробная часть;
- забывать скобки в формуле;
- путать `**` и умножение;
- ожидать от `/` целого результата.
