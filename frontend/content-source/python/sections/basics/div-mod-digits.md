# Целочисленное деление и цифры

После урока вы сможете использовать `//` и `%` для работы с цифрами числа.

> **Фокус**
> - Нужно знать: `//` даёт целую часть деления, `%` — остаток.
> - Нужно уметь: получать последнюю цифру и отбрасывать последнюю цифру положительного целого числа.
> - Полезно знать: эти две операции часто используются вместе.

## Частное и остаток

Для положительных целых чисел удобно рассматривать деление как две связанные величины.

```python
number = 347
print(number // 10)
print(number % 10)
```

`347 // 10` равно `34`: последняя цифра отброшена.  
`347 % 10` равно `7`: получена последняя цифра.

Это даёт главный шаблон работы с десятичной записью числа.

## Извлекаем цифры

Для двузначного положительного числа десятки и единицы можно получить так:

```python
number = 58
tens = number // 10
ones = number % 10
print(tens, ones)
```

Для более длинного числа сначала отбрасывают ненужные младшие цифры с помощью `//`, а затем выделяют нужную цифру с помощью `% 10`.

Например, у числа `4827` цифру сотен можно получить выражением `(4827 // 100) % 10`.

## Почему шаблон работает

При делении на `10` остаток всегда содержит то, что не вошло в полные десятки. Для неотрицательного целого числа это последняя десятичная цифра. Целая часть деления содержит оставшуюся запись числа без этой цифры.

Точно так же `% 100` оставляет две последние цифры, а `// 100` отбрасывает две последние цифры.

## Частые ошибки

- менять местами `//` и `%`;
- использовать обычное `/`, когда нужен целый результат;
- забывать скобки в выражении для средней цифры;
- применять шаблон к отрицательным числам, не проверив требования задачи;
- путать «получить последнюю цифру» и «удалить последнюю цифру».
