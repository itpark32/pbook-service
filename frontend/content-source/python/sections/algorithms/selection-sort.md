# Простые сортировки

После урока вы сможете реализовывать сортировку выбором и понимать её шаги.

> **Фокус**
> - Нужно знать: на каждом внешнем шаге выбирается минимум оставшейся части.
> - Нужно уметь: хранить индекс лучшего кандидата и ставить его на очередную позицию.
> - Полезно знать: после шага позиция `left` уже окончательно отсортирована.

## Сортировка выбором

```python
numbers = [4, 1, 3, 2]

for left in range(len(numbers)):
    minimum = left

    for index in range(left + 1, len(numbers)):
        if numbers[index] < numbers[minimum]:
            minimum = index

    numbers[left], numbers[minimum] = numbers[minimum], numbers[left]

print(numbers)
```

Переменная `minimum` хранит индекс наименьшего элемента среди ещё не отсортированной части списка.

После обмена в позиции `left` оказывается правильный элемент.

## Инвариант внешнего цикла

После завершения шага `left` префикс списка до этой позиции включительно уже содержит самые маленькие элементы в правильном порядке.

Для `[4, 1, 3]` первый шаг находит `1` и получает:

`[1, 4, 3]`.

На следующем шаге первая позиция уже не рассматривается: она окончательно готова.

```python
numbers = [3, 3, 1]

left = 0
minimum = left

for index in range(left + 1, len(numbers)):
    if numbers[index] < numbers[minimum]:
        minimum = index

numbers[left], numbers[minimum] = numbers[minimum], numbers[left]
print(numbers)
```

Этот маленький пример показывает ровно один внешний шаг алгоритма.

## Стоимость алгоритма

Для каждой позиции приходится искать минимум в оставшемся хвосте. Поэтому число сравнений растёт примерно как квадрат длины списка.

Сортировка выбором полезна для понимания алгоритма, хотя в обычном Python применяются встроенные средства сортировки.

## Частые ошибки

- хранить минимальное значение, когда для обмена нужен его индекс;
- начинать внутренний цикл снова с нуля;
- выполнять обмен внутри внутреннего цикла;
- путать уже отсортированную и ещё не отсортированную части;
- считать один удачный обмен полным завершением сортировки.
