# Двоичный поиск

После урока вы сможете искать значение в отсортированном массиве за логарифмическое время.

> **Фокус**
> - Нужно знать: двоичный поиск работает на данных, где по сравнению можно отбросить половину диапазона.
> - Нужно уметь: поддерживать границы `left` и `right`.
> - Полезно знать: после проверки середины её нельзя оставлять в новом диапазоне, если уже доказано, что она не подходит.

## Диапазон возможного ответа

```python
values = [2, 5, 8, 13, 21]
target = 13

left = 0
right = len(values) - 1
position = -1

while left <= right:
    middle = (left + right) // 2

    if values[middle] == target:
        position = middle
        break

    if values[middle] < target:
        left = middle + 1
    else:
        right = middle - 1

print(position)
```

Перед каждой итерацией искомый элемент, если он существует, должен находиться внутри диапазона `left..right`.

Это и есть главный инвариант алгоритма.

## Почему границы сдвигаются на один

Если `values[middle] < target`, то сама позиция `middle` уже проверена и точно не является ответом. Все позиции слева от неё тоже не подходят, потому что список отсортирован.

Поэтому новая левая граница — `middle + 1`.

Аналогично при слишком большом среднем значении используется `middle - 1`.

```python
values = [1, 4, 7, 10, 15, 19]
target = 6
left = 0
right = len(values) - 1

while left <= right:
    middle = (left + right) // 2
    print(left, middle, right)

    if values[middle] < target:
        left = middle + 1
    else:
        right = middle - 1
```

По трассировке видно, что диапазон на каждом шаге строго уменьшается.

## Когда двоичный поиск уместен

Один поиск в маленьком несортированном наборе часто проще выполнить линейно. Двоичный поиск особенно полезен, когда данные уже отсортированы или запросов много.

Сортировать набор только ради одного поиска не всегда выгодно.

## Частые ошибки

- применять алгоритм к неотсортированному списку;
- писать `left = middle` или `right = middle` и получать несужающийся диапазон;
- путать индекс `middle` со значением `values[middle]`;
- неверно обрабатывать отсутствие элемента;
- ошибаться в условии завершения `left <= right`.
