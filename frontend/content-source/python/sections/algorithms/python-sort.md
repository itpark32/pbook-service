# sort, sorted и key

После урока вы сможете сортировать данные встроенными средствами и задавать ключ.

> **Фокус**
> - Нужно знать: `list.sort()` меняет список, `sorted(...)` возвращает новый список.
> - Нужно уметь: выбирать направление и задавать `key`.
> - Полезно знать: ключ возвращает значение, по которому Python сравнивает элементы.

## Два способа сортировки

```python
numbers = [5, 2, 8, 1]
copy_sorted = sorted(numbers)

print(numbers)
print(copy_sorted)
```

Исходный список не изменился.

Метод списка работает иначе:

```python
numbers = [5, 2, 8, 1]
numbers.sort(reverse=True)

print(numbers)
```

Теперь изменён сам `numbers`.

## Сортировка по ключу

Пусть есть пары `(имя, балл)`. Если нужен порядок по баллу, нужно явно указать, какое значение является ключом.

```python
students = [("Анна", 82), ("Борис", 95), ("Вика", 88)]
students.sort(key=lambda item: item[1], reverse=True)

print(students)
```

`key` не заменяет элемент. Он только сообщает, какое вычисленное значение использовать при сравнении.

## Выбор между `sort` и `sorted`

Используйте `sort`, если нужно изменить существующий список. Используйте `sorted`, если исходный порядок должен сохраниться или сортируется не сам список.

Параметр `reverse=True` меняет направление сортировки.

## Частые ошибки

- сохранять результат `numbers.sort()` в переменную и получать `None`;
- ожидать, что `sorted(numbers)` изменит `numbers`;
- писать ключ, который возвращает не тот критерий;
- вручную перестраивать данные вместо использования `key`;
- путать направление сортировки и критерий сортировки.
