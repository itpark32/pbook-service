# Линейный поиск

После урока вы сможете находить элемент и его индекс линейным проходом.

> **Фокус**
> - Нужно знать: линейный поиск проверяет элементы по одному.
> - Нужно уметь: отличать найденное значение от позиции, на которой оно найдено.
> - Полезно знать: нужно заранее решить, ищется первое вхождение, последнее или сам факт наличия.

## Поиск первого вхождения

```python
values = [8, 3, 5, 3]
target = 3
position = -1

for index in range(len(values)):
    if values[index] == target:
        position = index
        break

print(position)
```

`-1` означает, что подходящая позиция пока не найдена. После первого совпадения поиск можно закончить.

## Поиск без досрочного завершения

Если нужен последний индекс, прекращать цикл нельзя.

```python
values = [8, 3, 5, 3]
target = 3
position = -1

for index in range(len(values)):
    if values[index] == target:
        position = index

print(position)
```

Теперь каждое новое совпадение заменяет предыдущий индекс, поэтому в конце остаётся последняя позиция.

## Значение и индекс — разные ответы

Вопрос «есть ли число?» требует логического результата. Вопрос «где оно находится?» требует индекс. Вопрос «какое первое подходящее значение?» может вообще не требовать индекса.

Перед циклом определите, какой именно результат должен храниться.

## Частые ошибки

- возвращать значение вместо индекса;
- использовать `0` как признак «не найдено», хотя `0` — допустимый индекс;
- ставить `break`, когда требуется последнее вхождение;
- забывать обработать отсутствие элемента;
- продолжать поиск после первого совпадения, когда это не требуется.
