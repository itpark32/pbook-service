# Обработка списков

После урока вы сможете фильтровать, преобразовывать и агрегировать элементы списка.

> **Фокус**
> - Нужно знать: циклы, условия и накопители.
> - Нужно уметь: применять знакомые алгоритмы к элементам списка.
> - Полезно знать: список позволяет сохранить данные и пройти их повторно.

## Фильтрация вручную

Новый список собирают через `append`, добавляя только элементы, прошедшие условие.

```python
numbers = [3, -2, 8, -1, 5]
positive = []
for value in numbers:
    if value > 0:
        positive.append(value)
print(positive)
```

## Преобразование и агрегирование

Если нужен только один итоговый показатель, новый список не обязателен: достаточно накопителя.

```python
numbers = [2, 4, 6]
total = 0
for value in numbers:
    total += value * value
print(total)
```

## Частые ошибки

Не создавайте новый список, если нужен только итог. Перед преобразованием решите, меняете исходный список или строите новый.
