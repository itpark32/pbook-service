# Изменение списков

После урока вы сможете изменять элементы и осознанно применять методы списка.

> **Фокус**
> - Нужно знать: элемент списка можно заменить, добавить или удалить.
> - Нужно уметь: различать `append`, `insert`, `pop` и `remove`.
> - Полезно знать: `pop` работает с индексом, `remove` — со значением.

## Замена не меняет длину

```python
scores = [5, 3, 4]
scores[1] = 5

print(scores)
```

Элемент с индексом `1` заменён. Длина списка осталась равной трём.

В пустом списке нельзя выполнить `numbers[0] = 10`: позиции `0` ещё не существует.

## Добавление и удаление

```python
guests = ["Анна", "Борис"]
guests.append("Вика")
guests.insert(1, "Глеб")
deleted = guests.pop(0)

print(deleted)
print(guests)
```

`append` добавляет элемент в конец. `insert(index, value)` вставляет перед указанной позицией. `pop(index)` удаляет элемент по индексу и возвращает его.

`remove(value)` удаляет первое найденное значение, а не элемент с таким индексом.

## Методы меняют существующий список

`append` выполняет изменение на месте и не возвращает новый список. Поэтому запись `result = numbers.append(3)` оставит в `result` значение `None`.

Перед методом полезно спросить: я указываю позицию или значение? Этот вопрос помогает не путать `pop` и `remove`.

## Частые ошибки

- использовать `remove(1)`, когда нужно удалить элемент с индексом `1`;
- ожидать новый список от `append`;
- присваивать элементу несуществующего индекса;
- забывать, что `remove` удаляет только первое совпадение;
- путать замену существующего элемента с добавлением нового.
