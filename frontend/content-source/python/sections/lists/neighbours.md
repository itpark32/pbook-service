# Соседи, пары и тройки

После урока вы сможете обрабатывать соседние элементы без выхода за границы.

> **Фокус**
> - Нужно знать: для пары `i` и `i + 1` последний допустимый `i` меньше последнего индекса.
> - Нужно уметь: выбирать диапазон индексов по числу элементов окна.
> - Полезно знать: маленькие списки естественно дают пустой диапазон перебора.

## Соседняя пара

```python
numbers = [4, 7, 2, 9]
count = 0

for index in range(len(numbers) - 1):
    if numbers[index] < numbers[index + 1]:
        count += 1

print(count)
```

Цикл заканчивается на предпоследнем индексе. Поэтому `index + 1` всегда существует.

## Тройка соседей

```python
numbers = [1, 3, 2, 5, 4]

for index in range(1, len(numbers) - 1):
    left = numbers[index - 1]
    current = numbers[index]
    right = numbers[index + 1]

    if current > left and current > right:
        print(index)
```

Здесь текущий элемент должен иметь и левого, и правого соседа. Поэтому крайние элементы не рассматриваются.

## Диапазон следует из нужных обращений

Не запоминайте границы механически. Сначала выпишите все индексы, которые используются внутри тела: `i`, `i + 1`, `i - 1` и т. д. Затем выберите такие значения `i`, при которых каждый индекс остаётся допустимым.

## Частые ошибки

- доходить до последнего индекса при использовании `i + 1`;
- начинать с нуля при использовании `i - 1`;
- считать крайний элемент имеющим двух соседей;
- ошибаться на единицу в `range`;
- не проверять список длины `0`, `1` или `2`.
