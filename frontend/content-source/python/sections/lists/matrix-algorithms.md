# Алгоритмы обработки матриц

После урока вы сможете считать характеристики строк, столбцов и диагоналей.

> **Фокус**
> - Нужно знать: двумерные списки и вложенные циклы.
> - Нужно уметь: выбирать порядок обхода под нужную характеристику.
> - Полезно знать: строка, столбец и диагональ требуют разных индексов.

## Характеристика строки

Если нужен отдельный ответ для каждой строки, накопитель создаётся заново перед обходом этой строки.

```python
matrix = [[1, 2, 3], [4, 5, 6]]
for row in matrix:
    total = 0
    for value in row:
        total += value
    print(total)
```

## Столбец и диагональ

Для столбца фиксируют его номер и меняют строку. На главной диагонали квадратной матрицы номера строки и столбца совпадают.

```python
matrix = [[1, 2], [3, 4]]
column_total = 0
for row in range(len(matrix)):
    column_total += matrix[row][1]
diagonal = 0
for i in range(len(matrix)):
    diagonal += matrix[i][i]
print(column_total, diagonal)
```

## Частые ошибки

Не забывайте сбрасывать накопитель между строками. Для диагонали убедитесь, что `matrix[i][i]` допустим.
