# Алгоритмы обработки матриц

После урока вы сможете считать характеристики строк, столбцов и диагоналей.

> **Фокус**
> - Нужно знать: разные характеристики матрицы требуют разного порядка обхода.
> - Нужно уметь: накапливать суммы строк, столбцов и работать с координатами.
> - Полезно знать: на главной диагонали индексы равны, на побочной их сумма равна `n - 1`.

## Суммы строк

```python
matrix = [[1, 2, 3], [4, 5, 6]]

for row in range(len(matrix)):
    row_sum = 0
    for column in range(len(matrix[row])):
        row_sum += matrix[row][column]
    print(row_sum)
```

`row_sum` обнуляется перед обработкой каждой новой строки.

## Максимум и его координаты

```python
matrix = [[4, 9], [7, 3]]
maximum = matrix[0][0]
best_row = 0
best_column = 0

for row in range(len(matrix)):
    for column in range(len(matrix[row])):
        if matrix[row][column] > maximum:
            maximum = matrix[row][column]
            best_row = row
            best_column = column

print(maximum, best_row, best_column)
```

Здесь состояние включает не только лучшее значение, но и место, где оно найдено.

## Диагонали квадратной матрицы

Для главной диагонали позиции имеют вид `matrix[i][i]`. Для побочной — `matrix[i][n - 1 - i]`.

Суммы столбцов требуют другого порядка: фиксируется номер столбца, а затем перебираются строки.

## Частые ошибки

- обнулять сумму строки внутри внутреннего цикла;
- обновлять максимум, но забывать координаты;
- применять формулу диагонали к неквадратной матрице без проверки условия;
- путать номера строк и столбцов;
- считать столбец существующим во всех строках, если структура может быть неровной.
