# elif и диапазоны

После урока вы сможете разбивать значения на несколько взаимоисключающих диапазонов.

> **Фокус**
> - Нужно знать: цепочка `if / elif / else` проверяется сверху вниз.
> - Нужно уметь: правильно располагать границы диапазонов.
> - Полезно знать: после первой истинной ветви остальные условия уже не проверяются.

## Несколько взаимоисключающих вариантов

Когда вариантов больше двух, используют `elif`.

```python
score = int(input())

if score >= 90:
    print("5")
elif score >= 75:
    print("4")
elif score >= 60:
    print("3")
else:
    print("2")
```

Если `score == 80`, первая проверка ложна, вторая истинна. После этого цепочка заканчивается.

## Порядок условий имеет смысл

В примере сначала проверяются большие значения. Если начать с `score >= 60`, то значение `95` сразу попадёт в эту ветвь и до `score >= 90` программа не дойдёт.

Диапазоны должны покрывать нужные значения без случайных дыр и пересечений.

```python
age = int(input())

if age < 7:
    print("дошкольник")
elif age < 18:
    print("школьный возраст")
else:
    print("18+")
```

Во второй ветви уже известно, что `age >= 7`, потому что первая проверка оказалась ложной. Поэтому не обязательно повторять обе границы.

## Проверяйте границы

Для порогов `7` и `18` полезно проверить как минимум `6`, `7`, `17`, `18`. Такие тесты быстро обнаруживают неверный знак `<` или `<=`.

## Частые ошибки

- ставить широкое условие раньше более строгого;
- терять значение на границе;
- писать несколько независимых `if`, хотя варианты взаимоисключающие;
- повторять в каждом `elif` уже известные ограничения и усложнять условие;
- забывать, что после первой истинной ветви цепочка прекращается.
