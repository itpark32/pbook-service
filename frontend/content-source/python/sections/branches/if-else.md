# if и else

После урока вы сможете выбирать ровно один из двух вариантов с if и else.

> **Фокус**
> - Нужно знать: сравнения и логические значения.
> - Нужно уметь: выполнять один блок при истинном условии и другой при ложном.
> - Полезно знать: `else` относится к тому же выбору, что и соответствующий `if`.

## Два взаимоисключающих пути

Если у задачи ровно два случая, `if` проверяет условие первого, а `else` обрабатывает всё остальное. За запуск выполняется одна ветвь.

```python
temperature = int(input())
if temperature >= 0:
    print("плюс")
else:
    print("минус")
```

## Граница принадлежит одной ветви

Перед кодом решите, куда попадёт значение на границе. Знак `>=` или `>` меняет ответ именно там.

```python
number = int(input())
if number % 2 == 0:
    print("чётное")
else:
    print("нечётное")
```

## Частые ошибки

Не пишите второй независимый `if`, если случаи взаимно исключают друг друга. Следите за отступами.
