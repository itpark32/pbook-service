# if и else

После урока вы сможете выбирать ровно один из двух вариантов с `if` и `else`.

> **Фокус**
> - Нужно знать: условие после `if` вычисляется в `True` или `False`.
> - Нужно уметь: записывать две взаимоисключающие ветви.
> - Полезно знать: отступ определяет, какие команды относятся к ветви.

## Программа выбирает ветвь

`if` проверяет условие. Если оно истинно, выполняется блок после `if`. Иначе выполняется блок после `else`.

```python
temperature = int(input())

if temperature >= 0:
    print("плюсовая температура")
else:
    print("мороз")
```

Для одного значения выполняется только одна из двух ветвей.

## Отступ — часть синтаксиса

Команды внутри ветви записываются с одинаковым отступом.

```python
number = int(input())

if number % 2 == 0:
    print("чётное")
    print("делится на 2")
else:
    print("нечётное")
```

Вторая строка `print` относится к `if`, потому что имеет тот же отступ. Команда без отступа выполнялась бы уже после всего ветвления.

## Особое внимание границе

Если условие содержит `>=`, значение на границе относится к первой ветви. Перед запуском полезно проверить значение чуть меньше границы, саму границу и значение чуть больше.

## Частые ошибки

- забыть `:` после условия;
- написать `=` вместо `==` в сравнении;
- поставить неправильный отступ;
- неверно решить, куда относится граничное значение;
- писать два независимых `if`, когда по условию нужен ровно один из двух вариантов.
