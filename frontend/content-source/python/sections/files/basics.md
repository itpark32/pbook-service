# Чтение и запись файлов

После урока вы сможете безопасно читать и записывать текстовые файлы.

> **Фокус**
> - Нужно знать: файл открывают в нужном режиме и закрывают после работы.
> - Нужно уметь: читать текст через `with open(...)`.
> - Полезно знать: режим `"r"` читает, `"w"` создаёт или перезаписывает файл.

## Чтение через контекстный менеджер

```python
with open("input.txt", "r", encoding="utf-8") as file:
    text = file.read()

print(text)
```

Блок `with` автоматически закрывает файл после завершения работы.

`read()` возвращает содержимое как строку. Дальше к этой строке можно применять уже знакомые строковые алгоритмы.

## Запись результата

```python
result = "42"

with open("output.txt", "w", encoding="utf-8") as file:
    file.write(result)
```

Режим `"w"` перезаписывает содержимое файла. Поэтому его нельзя использовать для чтения исходных данных, которые нужно сохранить.

Для текстовых файлов полезно явно указывать `encoding="utf-8"`.

## Путь к файлу

Относительный путь считается от рабочей папки программы. Если Python сообщает, что файл не найден, сначала проверьте имя, расширение и рабочую директорию.

Не усложняйте работу с файлами: после чтения данные превращаются в знакомые строки и числа, а основная алгоритмическая часть остаётся прежней.

## Частые ошибки

- открывать входной файл в режиме `"w"`;
- забывать, что `read()` возвращает строку;
- использовать неверное имя или путь;
- считать символ перевода строки частью числа;
- забывать преобразовать прочитанный текст перед арифметикой.
