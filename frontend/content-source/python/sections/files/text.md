# Текстовые данные в файлах

После урока вы сможете обрабатывать строки, слова и частоты из файла.

> **Фокус**
> - Нужно знать: строка файла может содержать перевод строки в конце.
> - Нужно уметь: очищать строки и применять к ним знакомые строковые алгоритмы.
> - Полезно знать: словарь частот удобно строить во время одного прохода по файлу.

## Читаем строки по одной

```python
with open("text.txt", "r", encoding="utf-8") as file:
    for line in file:
        clean = line.strip()
        print(clean)
```

`strip()` удаляет пробельные символы по краям, включая обычный перевод строки.

Исходный файл при этом не меняется.

## Считаем частоты слов

```python
frequency = {}

with open("text.txt", "r", encoding="utf-8") as file:
    for line in file:
        for word in line.lower().split():
            if word not in frequency:
                frequency[word] = 0
            frequency[word] += 1

print(frequency)
```

Здесь объединяются уже знакомые идеи: чтение файла, обработка строк и словарь частот.

После каждого слова словарь описывает частоты всей уже просмотренной части текста.

## Определите правила текста заранее

Нужно понимать, что считается словом и как обрабатываются регистр и знаки препинания. Эти правила должны следовать условию задачи.

Не добавляйте сложную очистку автоматически: если условие гарантирует только буквы и пробелы, этого достаточно.

## Частые ошибки

- забывать перевод строки в конце `line`;
- считать `"Word"` и `"word"` одинаковыми без явного приведения регистра;
- использовать правила очистки, которых нет в условии;
- читать весь большой файл, когда достаточно построчного прохода;
- путать частоту слова с фактом его наличия.
