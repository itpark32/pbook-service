## Построчная обработка

Каждую строку можно очистить и обработать отдельно. Это удобно для счётчиков и поиска.

```python
count = 0
with open("text.txt", "r", encoding="utf-8") as file:
    for line in file:
        clean = line.strip()
        if clean != "":
            count += 1
print(count)
```

## Частоты слов

Разбейте нормализованную строку на слова и обновляйте обычный частотный словарь.

```python
frequency = {}
with open("text.txt", "r", encoding="utf-8") as file:
    for line in file:
        words = line.lower().split()
        for word in words:
            if word not in frequency:
                frequency[word] = 0
            frequency[word] += 1
print(frequency)
```

## Частые ошибки

Нормализуйте регистр, если `Python` и `python` должны совпадать. `.split()` не удаляет всю пунктуацию.
