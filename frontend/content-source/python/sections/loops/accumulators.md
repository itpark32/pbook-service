# Счётчики, суммы и произведения

После урока вы сможете накапливать количество, сумму и произведение.

> **Фокус**
> - Нужно знать: счётчик и сумма обычно начинаются с нуля, произведение — с единицы.
> - Нужно уметь: сформулировать, что хранит накопитель после каждого шага.
> - Полезно знать: обновление накопителя выполняют только для тех элементов, которые подходят условию.

## Накопитель хранит результат уже просмотренной части

```python
count = 0
total = 0

for number in [4, -2, 7, 3]:
    if number > 0:
        count += 1
        total += number

print(count, total)
```

После каждого шага `count` означает количество уже просмотренных положительных чисел, а `total` — их сумму.

Именно смысл переменной помогает восстановить правильное обновление.

## Произведение начинается с единицы

```python
product = 1

for number in [2, 3, 4]:
    product *= number

print(product)
```

Если начать произведение с нуля, оно навсегда останется нулём. Поэтому нейтральное начальное значение зависит от операции.

## Обновление должно находиться в правильном месте

Если суммируются только подходящие элементы, `total += number` должен находиться внутри соответствующего `if`. Если вынести его наружу, в сумму попадут все элементы.

Хороший способ проверки — после каждой итерации словами сказать, что теперь хранит накопитель.

## Частые ошибки

- создавать `count = 0` или `total = 0` внутри цикла;
- прибавлять все элементы вместо подходящих;
- начинать произведение с нуля;
- путать количество и сумму;
- обновлять накопитель до проверки условия, когда это меняет смысл результата.

## Перед практикой

Перед кодом закончите фразу: «После обработки первых `k` элементов переменная ... хранит ...». Это и есть смысл вашего накопителя.
