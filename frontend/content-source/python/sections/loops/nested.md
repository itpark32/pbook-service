# Вложенные циклы

После урока вы сможете строить перебор пар и таблиц вложенными циклами.

> **Фокус**
> - Нужно знать: `for`, `range` и условия.
> - Нужно уметь: понимать, сколько раз выполняется внутренний цикл.
> - Полезно знать: для каждой итерации внешнего внутренний цикл начинается заново.

## Два уровня перебора

Внешний цикл выбирает первое значение, внутренний — все варианты второго. Так перебираются пары и клетки таблицы.

```python
for row in range(2):
    for column in range(3):
        print(row, column)
```

## Количество операций перемножается

Если внешний цикл выполняется `n` раз, а внутренний `m`, внутреннее тело выполняется `n * m` раз.

```python
for a in range(1, 4):
    for b in range(1, 4):
        if a < b:
            print(a, b)
```

## Частые ошибки

Не путайте переменные внешнего и внутреннего цикла. Следите за отступами.
