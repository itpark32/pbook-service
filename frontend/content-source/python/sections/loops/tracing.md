# Трассировка программ

После урока вы сможете пошагово определять значения переменных и результат программы.

> **Фокус**
> - Нужно знать: трассировка фиксирует состояние программы после отдельных команд или итераций.
> - Нужно уметь: вести таблицу значений переменных.
> - Полезно знать: трассировка помогает находить логические ошибки и ошибки на единицу.

## Не угадывайте результат — выполняйте код вручную

```python
total = 0

for number in [2, 5, 4]:
    if number % 2 == 0:
        total += number

print(total)
```

Удобно построить таблицу:

| `number` | условие | `total` после шага |
|---:|---|---:|
| 2 | True | 2 |
| 5 | False | 2 |
| 4 | True | 6 |

Так видно не только окончательный ответ, но и смысл каждого промежуточного состояния.

## Для `while` особенно важны границы

```python
x = 1
steps = 0

while x < 10:
    x *= 2
    steps += 1

print(x, steps)
```

Проследите пары `(x, steps)`: `(1, 0)`, `(2, 1)`, `(4, 2)`, `(8, 3)`, `(16, 4)`. После этого условие `x < 10` уже ложно.

Важно договориться, записываете ли вы состояние до или после тела цикла, и придерживаться одного правила.

## Что помещать в таблицу

Записывайте только переменные, которые влияют на дальнейшее решение или ответ. Для условия полезно отдельно отмечать его истинность.

Если программа даёт неверный результат, сравните ожидаемую трассу с фактической и найдите первую строку, где значения разошлись.

## Частые ошибки

- перескакивать через несколько итераций «в уме»;
- обновлять переменные в таблице в другом порядке, чем в программе;
- забывать, что условие `while` проверяется до очередной итерации;
- не фиксировать значение на границе;
- записывать слишком много несущественных данных и терять смысл трассировки.

## Проверьте себя

1. Зачем нужна трассировочная таблица?
2. В каком порядке нужно обновлять значения?
3. Почему полезно записывать результат условия?
4. Как трассировка помогает найти ошибку на единицу?
5. Что означает «первый шаг расхождения»?

## Перед практикой

Не запускайте программу сразу. Сначала выполните хотя бы несколько шагов вручную и только затем сравните свою таблицу с реальным результатом.
