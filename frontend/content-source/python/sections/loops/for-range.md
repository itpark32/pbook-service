# Цикл for и range

После урока вы сможете перебирать известный диапазон значений.

> **Фокус**
> - Нужно знать: `range(start, stop, step)` не включает `stop`.
> - Нужно уметь: выбирать границы диапазона по условию задачи.
> - Полезно знать: `for` особенно удобен, когда число повторений известно заранее.

## `for` перебирает значения

```python
for number in range(1, 6):
    print(number)
```

Будут выведены числа от `1` до `5`. Правая граница `6` не входит в диапазон.

Если указать только один аргумент, отсчёт начинается с нуля.

```python
for index in range(4):
    print(index)
```

Результат: `0`, `1`, `2`, `3`.

## Начало, конец и шаг

`range(start, stop, step)` задаёт первое значение, недостижимую правую границу и шаг.

```python
for number in range(10, 1, -2):
    print(number)
```

Получим `10`, `8`, `6`, `4`, `2`.

При отрицательном шаге левая и правая границы должны соответствовать движению вниз.

## Как выбрать границы

Если по условию нужно перебрать натуральные числа от `a` до `b` включительно, типичный диапазон — `range(a, b + 1)`.

Если перебираются индексы списка длины `n`, типичный диапазон — `range(n)`, потому что последний индекс равен `n - 1`.

## Частые ошибки

- считать, что `stop` входит в `range`;
- писать `range(a, b)`, когда `b` по условию должно обрабатываться;
- забывать отрицательный шаг при движении вниз;
- использовать неверную начальную позицию для индексов;
- выбирать `while`, когда нужен простой известный диапазон.
