# Цикл while

После урока вы сможете повторять действия, пока условие истинно.

> **Фокус**
> - Нужно знать: условие `while` проверяется перед каждой итерацией.
> - Нужно уметь: изменять состояние так, чтобы цикл когда-нибудь завершился.
> - Полезно знать: перед запуском полезно назвать условие продолжения цикла словами.

## Цикл повторяет блок, пока условие истинно

```python
number = 1

while number <= 5:
    print(number)
    number += 1
```

Перед первой итерацией Python проверяет `number <= 5`. После выполнения тела значение `number` увеличивается, затем условие проверяется снова.

Когда `number` станет равен `6`, условие будет ложным и цикл завершится.

## Состояние должно изменяться

Главный вопрос для `while`: что меняется на каждой итерации?

```python
value = 64

while value > 1:
    value //= 2
    print(value)
```

Здесь `value` уменьшается, поэтому условие `value > 1` неизбежно станет ложным.

Если переменные, участвующие в условии, не меняются в нужную сторону, цикл может не завершиться.

## Цикл может не выполниться ни разу

Если условие ложно уже до первого шага, тело `while` не выполняется.

Это важно отличать от рассуждения «цикл обязательно сделает хотя бы одну итерацию».

## Частые ошибки

- забыть изменить переменную из условия;
- менять её не в ту сторону;
- ошибиться на единицу в условии `<` и `<=`;
- ожидать хотя бы одну итерацию при изначально ложном условии;
- не проследить значения вручную на маленьком примере.

Перед написанием `while` сформулируйте три вещи: начальное состояние, условие продолжения и изменение состояния на каждом шаге.
