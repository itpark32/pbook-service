# Словари и частоты

После урока вы сможете связывать ключи со значениями и строить таблицы частот.

> **Фокус**
> - Нужно знать: словарь хранит пары `ключ → значение`.
> - Нужно уметь: добавлять ключ, изменять значение и считать частоты.
> - Полезно знать: проверка наличия ключа нужна перед первым увеличением счётчика.

## Ключ даёт доступ к связанному значению

```python
student = {
    "name": "Анна",
    "score": 87,
}

print(student["name"])
print(student["score"])
```

В списке доступ идёт по позиции, а в словаре — по ключу.

## Таблица частот

```python
values = [3, 1, 3, 2, 3, 1]
frequency = {}

for value in values:
    if value not in frequency:
        frequency[value] = 0
    frequency[value] += 1

print(frequency)
```

После обработки очередного элемента `frequency[value]` хранит, сколько раз это значение уже встретилось.

Такой словарь превращает вопрос о повторах в работу с ключами и их счётчиками.

## Перебор словаря

Можно перебирать ключи, значения или пары ключ-значение. Выбор зависит от задачи. Не полагайтесь на позицию элемента словаря как на смысл данных: ключ должен сам описывать, к чему относится значение.

## Частые ошибки

- увеличивать `frequency[value]` до создания ключа;
- путать ключ и связанное с ним значение;
- использовать список там, где ключи не являются компактными индексами;
- хранить частоту в множестве;
- менять словарь так, что теряется смысл его значений.

## Перед практикой

Сформулируйте пары данных словами: «для каждого ключа я хочу хранить ...». Это определит структуру словаря.
