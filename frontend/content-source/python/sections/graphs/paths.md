# Пути и расстояния в невзвешенном графе

После урока вы сможете находить расстояния и восстанавливать пути в невзвешенном графе.

> **Фокус**
> - Нужно знать: BFS, очередь и список смежности.
> - Нужно уметь: хранить расстояние от старта и родителя каждой найденной вершины.
> - Полезно знать: первая встреча вершины в BFS даёт минимальное число рёбер.

## Расстояния по слоям

`distance[v] = -1` означает, что вершина не достигнута. При первой встрече соседа его расстояние на единицу больше текущего.

```python
graph = [[1, 2], [0, 3], [0, 3], [1, 2]]
start = 0
distance = [-1] * len(graph)
distance[start] = 0
queue = [start]
head = 0
while head < len(queue):
    vertex = queue[head]
    head += 1
    for neighbour in graph[vertex]:
        if distance[neighbour] == -1:
            distance[neighbour] = distance[vertex] + 1
            queue.append(neighbour)
print(distance)
```

## Родители восстанавливают путь

При первой встрече соседа запомните, из какой вершины пришли. Затем идите от финиша назад по `parent`.

```python
parent = [None, 0, 0, 1]
finish = 3
path = []
vertex = finish
while vertex is not None:
    path.append(vertex)
    vertex = parent[vertex]
path.reverse()
print(path)
```

## Частые ошибки

Не используйте DFS для гарантированно кратчайшего пути по числу рёбер. Если финиш не достигнут, путь восстанавливать нельзя.
