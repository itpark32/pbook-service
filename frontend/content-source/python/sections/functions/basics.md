# Функции: параметры и return

После урока вы сможете объявлять функции, передавать аргументы и возвращать результат.

> **Фокус**
> - Нужно знать: `def`, параметры, аргументы и `return`.
> - Нужно уметь: отделять вычисление от ввода и вывода.
> - Полезно знать: `return` возвращает значение и сразу завершает текущий вызов функции.

## Функция получает данные и возвращает результат

```python
def rectangle_area(width, height):
    return width * height

area = rectangle_area(4, 7)
print(area)
```

`width` и `height` — параметры функции. Значения `4` и `7` — аргументы конкретного вызова.

Перед написанием функции полезно определить её контракт: какие данные она получает и что должна вернуть.

## `return` и `print` решают разные задачи

```python
def is_even(number):
    return number % 2 == 0

result = is_even(8)
print(result)
```

`return` отдаёт значение вызывающему коду. Его можно сохранить в переменную, использовать в условии или передать другой функции.

`print` только показывает значение пользователю. Если вычислительная функция лишь печатает ответ, этот ответ сложнее использовать дальше.

## Несколько точек выхода

```python
def safe_divide(a, b):
    if b == 0:
        return None
    return a / b

print(safe_divide(10, 2))
```

Как только выполнен `return`, оставшаяся часть текущего вызова уже не исполняется.

Значение `None` здесь является частью договора: оно означает, что деление выполнить нельзя.

## Частые ошибки

- определить функцию, но забыть её вызвать;
- использовать `print` вместо `return`, когда результат нужен программе;
- путать параметр и аргумент;
- помещать `input()` внутрь вычислительной функции без необходимости;
- ожидать выполнение строк после сработавшего `return`.
