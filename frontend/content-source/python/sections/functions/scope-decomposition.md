# Декомпозиция и область видимости

После урока вы сможете разделять решение на функции и управлять локальными данными.

> **Фокус**
> - Нужно знать: переменная, созданная внутри функции, обычно локальна.
> - Нужно уметь: делить большую задачу на небольшие функции с понятными контрактами.
> - Полезно знать: передача данных через параметры и `return` делает связи между частями программы явными.

## Локальные данные принадлежат вызову функции

```python
def double(number):
    result = number * 2
    return result

answer = double(6)
print(answer)
```

`number` и `result` существуют внутри вызова `double`. Основной код получает только то значение, которое функция возвращает.

Так проще понимать, какие данные может изменить каждая часть программы.

## Разделяем разные обязанности

```python
def sum_positive(numbers):
    total = 0
    for number in numbers:
        if number > 0:
            total += number
    return total

values = [3, -2, 5]
print(sum_positive(values))
```

Функция решает одну законченную подзадачу: получает список и возвращает сумму положительных элементов.

Ввод, вывод и другие действия можно оставить в основной части программы.

## Хорошая декомпозиция

Разбивать программу на функции полезно не ради количества функций, а ради понятных частей.

Хорошая функция:

- имеет одну ясную цель;
- получает нужные данные через параметры;
- возвращает результат;
- не зависит от лишних внешних переменных;
- может быть проверена отдельно.

Слишком мелкое разбиение, где функция состоит из одной случайной строки без самостоятельного смысла, не делает программу понятнее.

## Частые ошибки

- полагаться на глобальную переменную вместо параметра;
- пытаться использовать локальную переменную снаружи;
- смешивать ввод, вычисление и вывод без необходимости;
- делать функцию сразу для нескольких несвязанных задач;
- забывать вернуть вычисленный результат.
