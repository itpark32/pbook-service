# Декомпозиция и область видимости

После урока вы сможете разделять решение на функции и управлять локальными данными.

> **Фокус**
> - Нужно знать: параметры и `return`.
> - Нужно уметь: выделять подзадачи и понимать, где доступна переменная.
> - Полезно знать: переменная внутри функции обычно локальная.

## Разделяем алгоритм

Функция должна иметь понятный вход и результат. Основной код читает данные, вызывает вычисления и выводит ответ.

```python
def count_positive(values):
    count = 0
    for value in values:
        if value > 0:
            count += 1
    return count

numbers = [3, -1, 5]
print(count_positive(numbers))
```

## Локальные переменные принадлежат вызову

Имена внутри функции не обязаны совпадать с именами снаружи. Передача параметром делает зависимость явной.

```python
def double(value):
    result = value * 2
    return result

number = 6
answer = double(number)
print(answer)
```

## Частые ошибки

Не полагайтесь на глобальные переменные, если значение можно передать параметром. Не дробите код на функции без смысловой подзадачи.
