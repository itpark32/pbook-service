# Системы счисления

После урока вы сможете переводить целые числа между позиционными системами.

> **Фокус**
> - Нужно знать: значение цифры зависит от её позиции и основания системы.
> - Нужно уметь: переводить число в десятичную систему и из десятичной.
> - Полезно знать: при переводе из десятичной системы остатки получают справа налево.

## Из системы с основанием `base` в десятичную

```python
digits = "1011"
base = 2
value = 0

for char in digits:
    value = value * base + int(char)

print(value)
```

На каждом шаге уже построенное значение сдвигается на один разряд умножением на основание, затем добавляется новая цифра.

Для `1011₂` получается `11`.

## Из десятичной системы

```python
number = 13
base = 2
digits = ""

while number > 0:
    digit = number % base
    digits = str(digit) + digits
    number //= base

print(digits)
```

Остаток `number % base` даёт младшую цифру. Затем эта цифра отбрасывается через `// base`.

Поскольку младшие цифры получаются первыми, их нужно добавлять в результат справа налево.

## Допустимые цифры

В системе с основанием `b` допустимы цифры от `0` до `b - 1`.

Для оснований выше `10` нужны дополнительные обозначения цифр. Если задача работает только с основаниями до `10`, обычного `int(char)` достаточно.

Отдельно обработайте число `0`: цикл `while number > 0` для него не выполнится.

## Частые ошибки

- считать запись числа обычным десятичным значением;
- использовать цифру, недопустимую для основания;
- собирать остатки в неправильном порядке;
- забывать особый случай нуля;
- путать основание исходной и целевой системы.
