# Простые числа и НОД

После урока вы сможете проверять простоту и вычислять НОД алгоритмом Евклида.

> **Фокус**
> - Нужно знать: простое число больше `1` и имеет ровно два положительных делителя.
> - Нужно уметь: искать нетривиальный делитель до квадратного корня.
> - Полезно знать: алгоритм Евклида заменяет пару `(a, b)` на `(b, a % b)`.

## Проверка простоты

```python
number = 29
is_prime = number > 1

divisor = 2
while divisor * divisor <= number and is_prime:
    if number % divisor == 0:
        is_prime = False
    divisor += 1

print(is_prime)
```

Если составное число имеет делитель больше квадратного корня, у него обязательно есть парный делитель меньше корня. Поэтому дальше проверять не нужно.

Числа `0` и `1` не являются простыми.

## Алгоритм Евклида

```python
a = 84
b = 30

while b != 0:
    a, b = b, a % b

print(a)
```

На каждом шаге НОД пары не меняется, а второе число становится меньше. Когда `b` становится равным нулю, в `a` остаётся НОД.

## Смысл важнее запоминания строк

Для простоты нужно доказать отсутствие подходящего делителя. Для НОД используется инвариант: замена пары на `(b, a % b)` сохраняет общий делитель.

Оба алгоритма сокращают лишний перебор благодаря математическому свойству задачи.

## Частые ошибки

- считать `1` простым числом;
- проверять делители до самого `number`;
- неверно завершать проверку у квадратного корня;
- менять только одну переменную в шаге Евклида;
- путать НОД с произведением или меньшим из чисел.
