## Сколько способов

Пусть `dp[i]` — число способов попасть в позицию i шагами на 1 или 2. В i можно прийти из i−1 и i−2.

```python
n = 6
dp = [0] * (n + 1)
dp[0] = 1
for i in range(1, n + 1):
    dp[i] += dp[i - 1]
    if i >= 2:
        dp[i] += dp[i - 2]
print(dp[n])
```

## Минимальная стоимость

Другая семья задач хранит не число вариантов, а лучший результат. Здесь `dp[i]` — минимальная цена дойти до клетки i.

```python
cost = [0, 5, 2, 7, 3]
dp = [0] * len(cost)
dp[0] = cost[0]
dp[1] = cost[1]
for i in range(2, len(cost)):
    dp[i] = cost[i] + min(dp[i - 1], dp[i - 2])
print(dp[-1])
```

## Частые ошибки

Не копируйте переход до определения состояния. Все состояния, от которых зависит `dp[i]`, должны быть уже посчитаны.
