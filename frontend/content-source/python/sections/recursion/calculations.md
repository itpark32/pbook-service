# Рекурсивные вычисления и трассировка

После урока вы сможете трассировать стек вызовов и проверять завершение рекурсии.

> **Фокус**
> - Нужно знать: каждый вызов имеет собственные параметры и ждёт завершения вложенного вызова.
> - Нужно уметь: раскладывать рекурсивное выражение до базы и собирать ответ обратно.
> - Полезно знать: одинаковое имя параметра в разных вызовах означает разные локальные значения.

## Раскрываем вызовы до базы

```python
def sum_to(number):
    if number == 0:
        return 0
    return number + sum_to(number - 1)

print(sum_to(3))
```

Трассировка:

`sum_to(3)` ждёт `sum_to(2)`;  
`sum_to(2)` ждёт `sum_to(1)`;  
`sum_to(1)` ждёт `sum_to(0)`;  
`sum_to(0)` возвращает `0`.

После этого результаты собираются обратно: `1`, затем `3`, затем `6`.

## Порядок вывода показывает стек вызовов

```python
def trace(number):
    print("вход", number)

    if number > 0:
        trace(number - 1)

    print("выход", number)

trace(2)
```

Сообщения `вход` идут по мере углубления. Сообщения `выход` появляются в обратном порядке, когда вложенные вызовы завершаются.

Это помогает увидеть, какие команды выполняются до рекурсивного вызова, а какие — после него.

## Проверка завершения

Нужно смотреть не только на базу, но и на последовательность аргументов: `5, 4, 3, 2, 1, 0` явно приближается к условию остановки.

Если аргумент иногда остаётся тем же или движется в другую сторону, рекурсия может не завершиться.

## Частые ошибки

- считать, что все вызовы используют одну общую локальную переменную;
- забывать выполнять часть кода после возврата из вложенного вызова;
- собирать результат в том же порядке, в котором выполнялось углубление;
- проверять только наличие базы, но не движение к ней;
- путать значение текущего вызова со значением родительского.
