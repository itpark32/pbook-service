# Основы рекурсии

После урока вы сможете задавать базовый случай и рекурсивный переход.

> **Фокус**
> - Нужно знать: функции, параметры и условия.
> - Нужно уметь: уменьшать задачу до более простого экземпляра того же вида.
> - Полезно знать: каждый рекурсивный путь должен прийти к базовому случаю.

## База останавливает рекурсию

Рекурсивная функция сначала проверяет самый простой случай. Без базы или без движения к ней вызовы продолжатся.

```python
def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n - 1)

print(factorial(5))
```

## Переход уменьшает задачу

Полезно проговорить: «чтобы решить задачу для n, мне достаточно ответа для меньшего n».

```python
def sum_to(n):
    if n == 1:
        return 1
    return n + sum_to(n - 1)

print(sum_to(4))
```

## Частые ошибки

Не пишите рекурсивный вызов до формулировки базы. Убедитесь, что аргумент приближается к ней.
