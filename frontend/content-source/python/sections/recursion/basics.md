# Основы рекурсии

После урока вы сможете задавать базовый случай и рекурсивный переход.

> **Фокус**
> - Нужно знать: рекурсивная функция вызывает саму себя для более простой версии задачи.
> - Нужно уметь: находить базовый случай и доказывать приближение к нему.
> - Полезно знать: без уменьшения задачи рекурсия не завершится.

## Два обязательных элемента

```python
def countdown(number):
    if number == 0:
        print("старт")
        return

    print(number)
    countdown(number - 1)

countdown(3)
```

Условие `number == 0` — базовый случай. В нём функция больше не вызывает себя.

В рекурсивном переходе используется `number - 1`, поэтому каждый следующий вызов становится ближе к базе.

## Рекурсивный результат

```python
def factorial(number):
    if number == 0:
        return 1

    return number * factorial(number - 1)

print(factorial(5))
```

Чтобы вычислить `factorial(5)`, функция временно ждёт результат `factorial(4)`, та — `factorial(3)` и так далее до базы.

После базового случая вызовы начинают завершаться в обратном порядке.

## Перед кодом задайте три вопроса

1. Что является самой простой задачей, ответ для которой известен сразу?
2. Как получить более простую версию исходной задачи?
3. Почему последовательность вызовов гарантированно дойдёт до базы?

Если на третий вопрос нет ответа, рекурсивное решение опасно запускать.

## Частые ошибки

- отсутствует базовый случай;
- рекурсивный аргумент не приближается к базе;
- база возвращает неверное нейтральное значение;
- рекурсивный вызов делается до проверки базы;
- попытка читать код как обычный цикл без учёта вложенных вызовов.
