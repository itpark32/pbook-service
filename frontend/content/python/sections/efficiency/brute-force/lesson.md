# Полный перебор

После урока вы сможете строить полный перебор и отсеивать неподходящие варианты.

> **Фокус**
> - Нужно знать: полный перебор рассматривает все допустимые кандидаты.
> - Нужно уметь: чётко задать пространство вариантов и условие проверки.
> - Полезно знать: правильный перебор должен быть полным, но не обязан генерировать заведомо невозможные варианты.

## Кандидат и проверка

```python
answers = []

for x in range(1, 20):
    if x % 3 == 0 and x % 5 == 1:
        answers.append(x)

print(answers)
```

Диапазон задаёт все кандидаты, а `if` оставляет только подходящие.

Главный вопрос: гарантированно ли любой возможный ответ попадает в перебираемый диапазон?

## Перебор нескольких параметров

```python
count = 0

for a in range(1, 5):
    for b in range(1, 5):
        if a + b == 5:
            count += 1

print(count)
```

Каждая пара `(a, b)` рассматривается отдельно. Такой перебор прост и надёжен для маленького пространства вариантов.

Перед оптимизацией полезно сначала построить корректный полный перебор и оценить его размер.

## Отсечение невозможного

Если из условия заранее известно, что кандидат не может быть ответом, его не обязательно генерировать. Но отсечение должно следовать из доказанного ограничения, а не из догадки.

Полный перебор часто удобен как эталонное решение для небольших ограничений.

## Частые ошибки

- задать слишком узкий диапазон и потерять ответ;
- считать только найденные примеры, не проверив полноту перебора;
- дублировать одни и те же варианты;
- оптимизировать до появления корректного базового решения;
- использовать перебор, который слишком велик для ограничений задачи.
