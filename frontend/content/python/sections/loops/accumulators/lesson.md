# Счётчики, суммы и произведения

После урока вы сможете накапливать количество, сумму и произведение.

> **Фокус**
> - Нужно знать: `for`, `if`, `+=` и `*=`.
> - Нужно уметь: выбирать начальное значение накопителя и объяснять его после каждого шага.
> - Полезно знать: `sum()` существует, но сначала алгоритм реализуем вручную.

## Три накопителя

Счётчик отвечает «сколько?», сумма — «сколько всего?», произведение — «каков общий множитель?». После обработки первых `i` чисел каждая переменная описывает только эти `i` чисел.

```python
count = 0
total = 0
for value in [3, -1, 5, 0]:
    if value > 0:
        count += 1
        total += value
print(count, total)  # 2 8
```

## Начальное значение

Сумма начинается с 0: прибавление нуля ничего не меняет. Произведение начинается с 1: умножение на единицу сохраняет первый множитель.

```python
product = 1
for value in [2, 3, 4]:
    product *= value
print(product)  # 24
```

## Частые ошибки

Не начинайте произведение с 0: результат навсегда останется нулём. Условие отбора ставят до обновления суммы.
