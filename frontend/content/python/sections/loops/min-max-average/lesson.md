# Минимум, максимум и среднее

После урока вы сможете находить экстремумы и среднее без хранения всей последовательности.

> **Фокус**
> - Нужно знать: минимум и максимум должны начинаться с допустимого кандидата.
> - Нужно уметь: обновлять лучшее найденное значение по мере прохода.
> - Полезно знать: для среднего нужны сумма и количество, а перед делением нужно проверить количество.

## Не начинайте максимум с нуля без причины

```python
numbers = [-8, -3, -10]
maximum = numbers[0]

for number in numbers:
    if number > maximum:
        maximum = number

print(maximum)
```

Ответ равен `-3`. Если бы `maximum` начинался с `0`, программа вернула бы значение, которого вообще нет в списке.

Первый элемент — честное начальное значение, если набор гарантированно непуст.

## Максимум среди подходящих значений

Если первый элемент может не подходить условию, удобно хранить отсутствие кандидата через `None`.

```python
best = None

for number in [7, 10, 13, 25]:
    if number % 5 == 0:
        if best is None or number > best:
            best = number

print(best)
```

Пока подходящего значения нет, `best is None`. После первого кандидата переменная уже хранит настоящий максимум.

## Среднее требует двух накопителей

Среднее — это `total / count`. Сначала обрабатывают всю последовательность, затем проверяют, что `count != 0`, и только после этого делят.

Искусственные значения вроде `-1000000` допустимы только при точно известных ограничениях. В общем случае первый элемент или `None` надёжнее выражают смысл состояния.

## Частые ошибки

- начинать максимум с нуля для отрицательных данных;
- брать первый элемент, не проверив, что он подходит условию;
- делить на `count`, который может остаться нулём;
- обновлять минимум или максимум неправильным знаком сравнения;
- смешивать поиск экстремума и вычисление среднего в одной непонятной переменной.
