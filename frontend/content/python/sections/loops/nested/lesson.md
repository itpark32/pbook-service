# Вложенные циклы

После урока вы сможете строить перебор пар и таблиц вложенными циклами.

> **Фокус**
> - Нужно знать: для каждого шага внешнего цикла внутренний цикл проходит полностью.
> - Нужно уметь: понимать пару текущих значений внешнего и внутреннего счётчиков.
> - Полезно знать: общее число итераций часто равно произведению размеров диапазонов.

## Один цикл находится внутри другого

```python
for row in range(3):
    for column in range(4):
        print(row, column)
```

Для `row == 0` внутренний цикл переберёт все четыре значения `column`. Затем `row` станет равен `1`, и внутренний цикл снова начнётся с начала.

Так естественно перебираются координаты таблицы и пары вариантов.

## Перебор пар

```python
for first in range(1, 4):
    for second in range(1, 4):
        print(first, second)
```

Каждая итерация соответствует одной упорядоченной паре `(first, second)`. Всего здесь `3 * 3 = 9` пар.

Если нужны только пары с дополнительным ограничением, проверку обычно выполняют внутри вложенного цикла.

## Следите за уровнем отступа

Команда, находящаяся внутри обоих циклов, выполняется для каждой пары. Команда внутри только внешнего цикла выполняется один раз после завершения внутреннего перебора для текущего внешнего значения.

Это различие удобно проверять трассировкой первых двух внешних итераций.

## Частые ошибки

- считать, что внутренний цикл выполняется только один раз;
- путать внешний и внутренний счётчики;
- ставить команду на неверный уровень отступа;
- неверно оценивать число пар;
- использовать вложенный перебор, когда достаточно одного прохода.
