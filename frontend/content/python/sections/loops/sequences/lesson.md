# Последовательности и ввод до стоп-сигнала

После урока вы сможете обрабатывать поток значений и корректно работать со стоп-сигналом.

> **Фокус**
> - Нужно знать: `while`, счётчики и накопители.
> - Нужно уметь: обрабатывать данные по одному без хранения всей последовательности.
> - Полезно знать: стоп-сигнал завершает ввод и обычно не входит в данные.

## Известное количество элементов

Если сначала дано `n`, программа читает ровно `n` значений. После каждой итерации накопитель описывает уже прочитанную часть.

```python
n = int(input())
total = 0
for _ in range(n):
    value = int(input())
    total += value
print(total)
```

## Ввод до специального значения

Если конец задаёт стоп-сигнал, сначала читают значение, затем проверяют его и только данные учитывают в ответе.

```python
value = int(input())
count = 0
while value != 0:
    if value > 0:
        count += 1
    value = int(input())
print(count)
```

## Частые ошибки

Не включайте стоп-сигнал в ответ без требования условия. Не храните все числа, если ответ поддерживается одним состоянием.
