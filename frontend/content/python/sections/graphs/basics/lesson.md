# Представление графа

После урока вы сможете хранить граф списками смежности.

> **Фокус**
> - Нужно знать: вершина, ребро, направление и вес.
> - Нужно уметь: переводить связи из условия в список смежности.
> - Полезно знать: у неориентированного ребра обычно нужны две записи, у ориентированного — одна.

## Граф описывает объекты и связи

```python
graph = {
    1: [2, 3],
    2: [4],
    3: [4],
    4: [],
}

print(graph[1])
```

Ключ — вершина, значение — список её соседей.

В ориентированном графе запись `1 -> 2` не означает автоматического ребра `2 -> 1`.

## Взвешенные рёбра

```python
weighted = {
    1: [(2, 5), (3, 2)],
    2: [(4, 3)],
    3: [(4, 7)],
    4: [],
}

print(weighted[1])
```

Пара `(2, 5)` означает ребро из вершины `1` в вершину `2` веса `5`.

На этом уроке важно только научиться читать и строить представление графа. Алгоритмы обхода и поиска путей будут отдельными темами.

## Из условия в модель

Сначала решите:

- что является вершинами;
- что является рёбрами;
- направлены ли рёбра;
- есть ли у них веса.

Для неориентированной дороги `a—b` соседство записывают в обе стороны. Вершины без исходящих рёбер тоже должны существовать в структуре.

Список рёбер удобен для перебора всех связей. Список смежности быстро даёт соседей конкретной вершины. Матрица смежности позволяет быстро проверить наличие отдельного ребра, но требует порядка `n²` ячеек.

## Частые ошибки

- считать ориентированное ребро двусторонним;
- путать число вершин и число рёбер;
- забывать вершину без соседей;
- менять местами соседа и вес;
- строить алгоритм до того, как модель графа из условия стала понятной.
