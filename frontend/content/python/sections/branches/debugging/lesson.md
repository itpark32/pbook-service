# Ошибки и отладка

После урока вы сможете находить синтаксические, исполнительные и логические ошибки.

> **Фокус**
> - Нужно знать: переменные, арифметику и условия.
> - Нужно уметь: локализовать место ошибки и проверять программу на маленьких примерах.
> - Полезно знать: не каждая неправильная программа завершается сообщением об ошибке.

## Три вида проблем

Синтаксическая ошибка мешает запустить программу. Ошибка выполнения возникает во время работы. Логическая ошибка не останавливает Python, но даёт неверный ответ.

```python
a = int(input())
b = int(input())
result = a / b
print(result)
```

## Трассировка логической ошибки

Если программа запускается, но отвечает неверно, подставьте маленькие данные и выпишите значения переменных после каждого действия.

```python
price = 120
discount = 20
final_price = price - price * discount / 100
print(final_price)
```

## Частые ошибки

Не меняйте сразу много строк: найдите первый момент, где состояние стало неправильным. В traceback ищите последнюю полезную строку своего кода.
