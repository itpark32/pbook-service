# Составные и вложенные условия

После урока вы сможете объединять и вкладывать условия без лишних ветвей.

> **Фокус**
> - Нужно знать: `and`, `or`, `not` и вложенный `if`.
> - Нужно уметь: выбирать между составным условием и вложенной проверкой.
> - Полезно знать: независимые действия не всегда нужно собирать в одну цепочку `elif`.

## Несколько требований в одной проверке

Если действие выполняется только при выполнении нескольких требований, их можно объединить.

```python
age = 16
has_permission = True

if age >= 14 and has_permission:
    print("доступ разрешён")
```

Здесь обе части должны быть истинны.

Если достаточно хотя бы одной причины, используют `or`.

## Когда полезно вложение

Иногда вторую проверку имеет смысл выполнять только после первой.

```python
number = int(input())

if number != 0:
    if number > 0:
        print("положительное ненулевое")
    else:
        print("отрицательное")
else:
    print("ноль")
```

Внутренний `if` рассматривается только тогда, когда уже известно, что число не равно нулю.

Слишком глубокие вложения усложняют чтение. Если условие естественно выражается через `and` или `or`, часто составное выражение проще.

## Независимые проверки — это не `elif`

Если программа должна выполнить несколько действий независимо друг от друга, используют несколько `if`.

```python
number = 30

if number % 2 == 0:
    print("делится на 2")

if number % 3 == 0:
    print("делится на 3")
```

Здесь допустимы сразу два сообщения, поэтому цепочка `elif` была бы неправильной.

## Частые ошибки

- использовать `elif`, когда должны сработать несколько независимых условий;
- строить лишние вложения вместо понятного `and`;
- заменять `and` на `or`;
- забывать скобки в длинном логическом выражении;
- отрицать всё условие, когда требуется отрицать только одну часть.
