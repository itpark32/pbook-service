# elif и диапазоны

После урока вы сможете разбивать значения на несколько взаимоисключающих диапазонов.

> **Фокус**
> - Нужно знать: `if/else`, сравнения и логика.
> - Нужно уметь: строить цепочку взаимоисключающих проверок через `elif`.
> - Полезно знать: срабатывает первая истинная ветвь.

## Когда случаев больше двух

Проверки идут сверху вниз. Как только одна ветвь подошла, остальные не рассматриваются. Поэтому диапазоны располагайте осознанно.

```python
score = int(input())
if score >= 90:
    print("5")
elif score >= 75:
    print("4")
elif score >= 60:
    print("3")
else:
    print("2")
```

## Диапазон можно задать явно

Если порядок проверок не позволяет опустить границу, используйте составное условие. Каждое значение должно попадать в один нужный диапазон.

```python
age = int(input())
if age < 7:
    print("дошкольник")
elif age >= 7 and age <= 17:
    print("школьник")
else:
    print("взрослый")
```

## Частые ошибки

Не ставьте широкую ветвь раньше узкой. Проверяйте точки, где один диапазон заканчивается, а другой начинается.
