# Делимость и делители

После урока вы сможете проверять делимость и эффективно перечислять делители.

> **Фокус**
> - Нужно знать: `a % b == 0` означает делимость `a` на `b`.
> - Нужно уметь: находить делители перебором до квадратного корня.
> - Полезно знать: делители обычно возникают парами `d` и `n // d`.

## Проверка делимости

```python
number = 42

if number % 7 == 0:
    print("делится")
else:
    print("не делится")
```

Остаток `0` означает, что число разбивается на целое количество частей по `7`.

## Делители приходят парами

Если `d` делит `n`, то `n // d` — второй делитель из той же пары.

```python
number = 36
divisors = []

for divisor in range(1, int(number ** 0.5) + 1):
    if number % divisor == 0:
        divisors.append(divisor)

        other = number // divisor
        if other != divisor:
            divisors.append(other)

print(sorted(divisors))
```

Достаточно проверять кандидатов до квадратного корня. Если оба делителя пары были бы больше корня, их произведение оказалось бы больше самого числа.

Для полного квадрата нужно не добавить один и тот же делитель дважды.

## Что именно требует задача

Иногда нужен:

- факт делимости;
- количество делителей;
- сумма делителей;
- список делителей;
- делители с дополнительным условием.

Не сохраняйте весь список, если для ответа достаточно счётчика или суммы.

## Частые ошибки

- путать `//` и `%`;
- начинать перебор делителей с нуля;
- проверять все числа до `n`, когда достаточно корня;
- дважды учитывать корень полного квадрата;
- сохранять делители без необходимости.
