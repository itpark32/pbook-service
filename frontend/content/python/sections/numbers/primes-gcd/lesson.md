# Простые числа и НОД

> **Фокус**

> - Нужно уметь: отличать поиск делителя от алгоритма Евклида.
> - Полезно знать: простое число больше 1 имеет только делители 1 и само себя.

## Проверка простоты

Чтобы доказать составность, достаточно найти делитель от 2 до квадратного корня.

```python
n = 29
prime = n > 1
d = 2
while d * d <= n and prime:
    if n % d == 0:
        prime = False
    d += 1
print(prime)
```

## Алгоритм Евклида

НОД пары `(a, b)` не меняется при переходе к `(b, a % b)`. Повторяем до нулевого второго значения.

```python
a = 84
b = 30
while b != 0:
    a, b = b, a % b
print(a)
```

## Частые ошибки

Не считайте 1 простым. В Евклиде обновляйте оба значения одновременно.
