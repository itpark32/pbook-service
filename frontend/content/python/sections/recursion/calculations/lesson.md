# Рекурсивные вычисления и трассировка

После урока вы сможете трассировать стек вызовов и проверять завершение рекурсии.

> **Фокус**
> - Нужно знать: базовый случай и рекурсивный переход.
> - Нужно уметь: понимать, какие значения ждут возврата из более глубокого вызова.
> - Полезно знать: каждый незавершённый вызов хранит свои локальные данные.

## Вызовы сначала углубляются

До базы предыдущие вызовы ждут результат более простого случая. После базы ответы возвращаются в обратном порядке.

```python
def power(base, exponent):
    if exponent == 0:
        return 1
    return base * power(base, exponent - 1)

print(power(2, 3))
```

## Трассировка обратного пути

Для суммы цифр каждый вызов отделяет последнюю цифру, а оставшееся число передаёт дальше.

```python
def sum_digits(number):
    if number < 10:
        return number
    return number % 10 + sum_digits(number // 10)

print(sum_digits(472))
```

## Частые ошибки

Не путайте порядок вызовов и возвратов. Если аргумент не становится проще, исправьте переход.
