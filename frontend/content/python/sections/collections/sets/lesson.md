# Кортежи и множества

После урока вы сможете хранить уникальные значения и выполнять операции над множествами.

> **Фокус**
> - Нужно знать: списки и циклы.
> - Нужно уметь: выбирать кортеж для неизменяемой записи и множество для уникальных элементов.
> - Полезно знать: множество не хранит повторяющиеся значения.

## Кортеж фиксирует запись

Кортеж похож на список, но его элементы нельзя заменить. Он удобен для координат и связанных значений.

```python
point = (3, 5)
x, y = point
print(x)
print(y)
```

## Множество хранит уникальные значения

`set` убирает повторы и быстро проверяет наличие. `&`, `|` и `-` дают пересечение, объединение и разность.

```python
first = {1, 2, 3, 3}
second = {3, 4}
print(first)
print(first & second)
print(first | second)
```

## Частые ошибки

Не рассчитывайте на порядок множества. Пустое множество создаётся как `set()`, потому что `{}` — пустой словарь.
