# Кортежи и множества

После урока вы сможете хранить уникальные значения и выполнять операции над множествами.

> **Фокус**
> - Нужно знать: кортеж неизменяем, множество хранит уникальные элементы.
> - Нужно уметь: использовать `in`, `add`, пересечение, объединение и разность.
> - Полезно знать: преобразование в `set` теряет повторы и исходный порядок.

## Кортеж как составное значение

```python
point = (3, 5)
x, y = point

print(x)
print(y)
```

Кортеж удобно использовать для небольшой записи из нескольких связанных значений, например координат.

Кортеж из одного элемента записывают с запятой: `(5,)`.

## Множество и уникальность

```python
a = {1, 2, 3}
b = {3, 4}

print(a & b)
print(a | b)
print(a - b)
```

`&` даёт пересечение, `|` — объединение, `-` — элементы первого множества, которых нет во втором.

Проверка `value in seen` подходит для вопроса «встречалось ли значение раньше?».

## Добавление и удаление

`add` добавляет элемент. `discard` безопасно ничего не делает, если элемента нет. `remove` при отсутствии элемента вызывает ошибку.

Множество не подходит, если важны количество повторов или исходный порядок.

## Частые ошибки

- ожидать сохранения повторов после `set(values)`;
- считать порядок элементов множества частью решения;
- путать разность `a - b` и `b - a`;
- забывать запятую в одноэлементном кортеже;
- использовать множество, когда требуется хранить частоты.
