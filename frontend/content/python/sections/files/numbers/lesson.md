# Числовые данные в файлах

После урока вы сможете обрабатывать числа из файла потоково.

> **Фокус**
> - Нужно знать: строки файла нужно преобразовывать в числа.
> - Нужно уметь: обновлять счётчик, сумму или экстремум без хранения всех данных.
> - Полезно знать: потоковая обработка использует память только для текущего состояния.

## Читаем числа по строкам

```python
total = 0

with open("numbers.txt", "r", encoding="utf-8") as file:
    for line in file:
        number = int(line)
        total += number

print(total)
```

На каждой итерации хранится одна строка файла и текущая сумма. Список всех чисел создавать не обязательно.

## Обработка по условию

```python
count = 0

with open("numbers.txt", "r", encoding="utf-8") as file:
    for line in file:
        number = int(line)
        if number > 0 and number % 2 == 0:
            count += 1

print(count)
```

Алгоритм внутри цикла ничем принципиально не отличается от обработки обычной последовательности.

Файл только поставляет очередное значение.

## Состояние важнее способа ввода

Для минимума, максимума и среднего применяются те же правила, что и раньше: корректное начальное значение, проверка отсутствия подходящих элементов, сумма вместе с количеством для среднего.

Большие файлы особенно показывают преимущество потоковой обработки: если для ответа не нужны все элементы одновременно, их не стоит сохранять.

## Частые ошибки

- забывать `int(line)`;
- хранить весь файл в списке без необходимости;
- считать пустую строку числом;
- неверно инициализировать максимум;
- смешивать чтение файла и логику так, что состояние становится непонятным.
