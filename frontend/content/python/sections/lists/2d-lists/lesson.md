# Двумерные списки

После урока вы сможете создавать матрицы и обходить строки и столбцы.

> **Фокус**
> - Нужно знать: `matrix[row][column]` сначала выбирает строку, затем элемент в ней.
> - Нужно уметь: обходить двумерный список вложенными циклами.
> - Полезно знать: строки матрицы должны быть независимыми списками.

## Два индекса

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
]

print(matrix[0][1])
print(matrix[1][2])
```

Первый индекс выбирает строку, второй — позицию внутри этой строки.

Число строк равно `len(matrix)`. Длина конкретной строки — `len(matrix[row])`.

## Обход всех элементов

```python
matrix = [[1, 2, 3], [4, 5, 6]]

for row in range(len(matrix)):
    for column in range(len(matrix[row])):
        print(row, column, matrix[row][column])
```

Такой вариант работает даже тогда, когда строки имеют разную длину.

## Независимые строки

Правильный прямоугольник из нулей:

```python
rows = 3
columns = 4
matrix = [[0] * columns for _ in range(rows)]
print(matrix)
```

Запись `[[0] * columns] * rows` повторяет ссылку на один внутренний список. Изменение одной ячейки может неожиданно изменить несколько строк.

## Частые ошибки

- менять местами строку и столбец;
- считать число столбцов через `len(matrix)` вместо длины строки;
- создавать матрицу умножением одного внутреннего списка;
- выходить за границы строки;
- предполагать, что любая двумерная структура обязательно прямоугольная.
