# Обработка списков

После урока вы сможете фильтровать, преобразовывать и агрегировать элементы списка.

> **Фокус**
> - Нужно знать: список можно проходить по значениям или по индексам.
> - Нужно уметь: считать, суммировать и строить новый список по условию.
> - Полезно знать: выбирайте перебор по индексам только тогда, когда позиция действительно нужна.

## Обработка по значениям

```python
numbers = [3, -2, 7, -5, 4]
total = 0

for number in numbers:
    if number > 0:
        total += number

print(total)
```

Здесь позиция элемента не важна, поэтому прямой перебор по значениям делает код проще.

## Строим новый список

```python
numbers = [1, 2, 3, 4, 5]
even = []

for number in numbers:
    if number % 2 == 0:
        even.append(number)

print(even)
```

Исходный список не меняется. В `even` после каждого шага находятся все подходящие элементы уже просмотренной части.

## Когда нужен индекс

Индекс нужен, если требуется сравнивать позицию, обращаться к соседям или изменять конкретное место. Если задача говорит только о значениях, перебор по самим элементам обычно понятнее.

Разделяйте три действия:

- фильтрация — оставить только подходящие элементы;
- преобразование — изменить каждый элемент по правилу;
- агрегация — получить один итог: сумму, количество, минимум и т. п.

## Частые ошибки

- использовать индексы без необходимости;
- изменять исходный список, хотя требуется построить новый;
- добавлять элемент в результат вне условия;
- путать количество с суммой;
- смешивать несколько разных результатов в одной переменной.
