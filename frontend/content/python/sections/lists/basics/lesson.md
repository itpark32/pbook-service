# Создание списка, ввод и индексы

После урока вы сможете создавать списки, читать элементы и обращаться по индексам.

> **Фокус**
> - Нужно знать: список хранит несколько значений, индексация начинается с `0`.
> - Нужно уметь: получать длину и безопасно обращаться к элементу.
> - Полезно знать: последний индекс равен `len(values) - 1`, а `-1` обращается к последнему элементу.

## Несколько значений под одним именем

```python
scores = [5, 4, 3, 5]

print(len(scores))
print(scores[0])
print(scores[-1])
```

`len(scores)` равно `4`. Допустимые неотрицательные индексы: `0`, `1`, `2`, `3`.

Индекс — позиция, значение — то, что хранится на этой позиции.

## Пустой список

```python
results = []

print(len(results))
```

Длина равна нулю. У такого списка нет первого элемента, поэтому `results[0]` вызовет `IndexError`.

Это важный граничный случай для любой программы, где список может оказаться пустым.

## Ввод списка чисел

Распространённая форма ввода — строка чисел через пробел, которую делят на части и преобразуют.

```python
numbers = list(map(int, input().split()))
print(numbers)
```

После преобразования элементы являются числами и готовы к арифметической обработке.

## Частые ошибки

- считать, что первый индекс равен `1`;
- использовать `values[len(values)]`;
- путать индекс и само значение;
- обращаться к элементу пустого списка;
- забывать преобразовать введённые строки в числа.
