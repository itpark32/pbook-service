# Линейный поиск

После урока вы сможете находить элемент и его индекс линейным проходом.

> **Фокус**
> - Нужно знать: списки, индексы и циклы.
> - Нужно уметь: последовательно проверять элементы и фиксировать найденную позицию.
> - Полезно знать: до текущего индекса все предыдущие элементы уже проверены.

## Поиск первого совпадения

Просматривайте элементы слева направо. Как только найдено первое совпадение, его индекс является ответом для первого вхождения.

```python
values = [8, 3, 5, 3]
target = 3
position = -1
for i in range(len(values)):
    if values[i] == target and position == -1:
        position = i
print(position)
```

## Поиск по условию

Искать можно не конкретное значение, а первый элемент, который удовлетворяет правилу.

```python
values = [4, 7, -2, 9]
position = -1
for i in range(len(values)):
    if values[i] < 0 and position == -1:
        position = i
print(position)
```

## Частые ошибки

Не используйте 0 как признак «не найдено»: индекс 0 настоящий. Если нужен первый элемент, не перезаписывайте ответ.
