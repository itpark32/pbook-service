# Сравнения и логика

После урока вы сможете составлять сравнения и логические выражения.

> **Фокус**
> - Нужно знать: `==`, `!=`, `<`, `<=`, `>`, `>=`, `and`, `or`, `not`.
> - Нужно уметь: получать логическое значение `True` или `False`.
> - Полезно знать: сложное условие лучше читать как обычную фразу.

## Сравнение возвращает логическое значение

Сравнение не изменяет данные. Оно отвечает на вопрос и возвращает `True` или `False`.

```python
age = 15
print(age >= 14)
print(age == 18)
```

Первое сравнение истинно, второе ложно.

`==` проверяет равенство, а `=` выполняет присваивание. Это разные операции.

## Несколько требований одновременно

Оператор `and` требует, чтобы обе части были истинны.

```python
age = 16
has_ticket = True
allowed = age >= 14 and has_ticket
print(allowed)
```

`or` требует истинности хотя бы одной части. `not` меняет логическое значение на противоположное.

Диапазон удобно записывать цепочкой сравнений:

```python
score = 73
inside = 60 <= score <= 80
print(inside)
```

Эта запись читается почти как математическое условие: значение находится от `60` до `80` включительно.

## Сначала сформулируйте условие словами

Перед кодом полезно сказать: «возраст не меньше 14 И билет есть» или «день — суббота ИЛИ воскресенье». После этого легче выбрать оператор и заметить ошибку.

Скобки используют, когда сложное выражение иначе читается неоднозначно.

## Частые ошибки

- писать `=` вместо `==`;
- использовать `and`, когда достаточно одного из условий;
- использовать `or`, когда обязательны оба условия;
- терять знак равенства на границе диапазона;
- отрицать не ту часть сложного выражения.
