# Целочисленное деление и цифры

После урока вы сможете использовать // и % для работы с цифрами числа.

> **Фокус**
> - Нужно знать: целые числа и арифметические операции.
> - Нужно уметь: получать частное без остатка, остаток и отдельные цифры.
> - Полезно знать: `% 10` даёт последнюю десятичную цифру неотрицательного числа.

## Частное и остаток

`a // b` показывает, сколько целых раз `b` помещается в `a`, а `a % b` — что осталось.

```python
minutes = int(input())
hours = minutes // 60
rest = minutes % 60
print(hours, rest)
```

## Как достать цифры

Для положительного трёхзначного числа последняя цифра получается через `% 10`, десятки — после удаления последней цифры.

```python
number = int(input())
ones = number % 10
tens = number // 10 % 10
hundreds = number // 100
print(hundreds, tens, ones)
```

## Частые ошибки

Не путайте `/` и `//`. Формулы для цифр зависят от разрядности, если она фиксирована условием.
