# Ввод, вывод и переменные

После урока вы сможете читать данные, сохранять их в переменных и выводить результат.

> **Фокус**
> - Нужно знать: `input()`, `print()` и правила записи имён переменных.
> - Нужно уметь: сохранять введённые строки и выводить значения в нужном порядке.
> - Полезно знать: `input()` всегда возвращает строку.

## Данные приходят по порядку

Каждый вызов `input()` читает одно значение. Если оно понадобится позже, сохраните его в переменной с понятным именем.

```python
name = input()
city = input()
print(name)
print(city)
```

## Переменная хранит значение

Присваивание связывает имя с текущим значением. Имя без кавычек означает переменную, а текст в кавычках — строковый литерал.

```python
first = input()
second = input()
print("Первое:", first)
print("Второе:", second)
```

## Частые ошибки

Не ставьте имя переменной в кавычки, если хотите вывести её значение. Порядок `input()` должен совпадать с форматом входных данных.
