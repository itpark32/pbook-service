# Состояние и серии символов

После урока вы сможете хранить состояние прохода и находить серии символов.

> **Фокус**
> - Нужно знать: `current` хранит длину текущей серии, `maximum` — лучший результат.
> - Нужно уметь: правильно сбрасывать состояние при разрыве серии.
> - Полезно знать: значение сброса зависит от смысла серии — иногда `1`, иногда `0`.

## Серия одинаковых символов

```python
text = "AAABBCCCCDAA"
current = 1
maximum = 1

for index in range(1, len(text)):
    if text[index] == text[index - 1]:
        current += 1
    else:
        current = 1

    if current > maximum:
        maximum = current

print(maximum)
```

`current` описывает серию, которая заканчивается в текущей позиции. При новом символе начинается новая серия длины `1`.

Для пустой строки нужен отдельный случай, потому что начального символа нет.

## Серия символов из разрешённого набора

```python
text = "AB1234CD56"
current = 0
maximum = 0

for char in text:
    if char in "0123456789":
        current += 1
        maximum = max(maximum, current)
    else:
        current = 0

print(maximum)
```

Здесь неподходящий символ не начинает новую подходящую серию, поэтому состояние сбрасывается в `0`.

Разницу между сбросом в `1` и в `0` лучше выводить из смысла `current`, а не запоминать как правило.

## Граничные случаи

Проверьте:

- пустую строку;
- один символ;
- лучшую серию в самом начале;
- лучшую серию в самом конце;
- отсутствие подходящих символов.

Серия в конце особенно полезна для проверки алгоритма, который ошибочно обновляет максимум только при разрыве.

## Частые ошибки

- начинать цикл с `0`, а затем обращаться к предыдущему символу;
- сбрасывать `current` не в то значение;
- обновлять максимум только при разрыве серии;
- забывать пустую строку;
- путать смысл текущей и максимальной серии.
