# Состояние и серии символов

После урока вы сможете хранить состояние прохода и находить серии символов.

> **Фокус**
> - Нужно знать: перебор строки, условия и максимум.
> - Нужно уметь: поддерживать длину текущей серии и лучший результат.
> - Полезно знать: при смене символа текущая серия начинается заново с длины 1.

## Текущая и лучшая серия

`current` — длина серии, заканчивающейся в текущем символе. `best` — максимум среди уже увиденных серий.

```python
text = "aaabbccccaa"
current = 1
best = 1
for i in range(1, len(text)):
    if text[i] == text[i - 1]:
        current += 1
    else:
        current = 1
    if current > best:
        best = current
print(best)
```

## Можно хранить предыдущий символ

При проходе без индекса отдельно храните предыдущий символ. После шага он должен стать текущим.

```python
text = "abbbcc"
previous = text[0]
current = 1
best = 1
for char in text[1:]:
    if char == previous:
        current += 1
    else:
        current = 1
    if current > best:
        best = current
    previous = char
print(best)
```

## Частые ошибки

Не сбрасывайте `best` при смене серии. Отдельно продумайте пустую строку, если она разрешена.
