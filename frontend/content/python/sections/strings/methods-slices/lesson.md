# Методы строк и срезы

После урока вы сможете преобразовывать строки методами и срезами.

> **Фокус**
> - Нужно знать: методы строк возвращают новый результат, а срез выбирает часть последовательности.
> - Нужно уметь: применять `lower`, `upper`, `strip`, `replace`, `split` и базовые срезы.
> - Полезно знать: правая граница среза не включается.

## Методы не меняют исходную строку

```python
text = "  Python  "
clean = text.strip().lower()

print(text)
print(clean)
```

`text` остаётся прежней строкой. Методы создают новое значение, которое нужно сохранить или сразу использовать.

`strip()` убирает пробелы по краям, `lower()` переводит буквы в нижний регистр, `upper()` — в верхний.

## Срез выбирает диапазон символов

```python
text = "programming"

print(text[0:7])
print(text[7:])
print(text[::-1])
```

В `text[start:stop]` позиция `stop` не входит в результат. Если начало или конец опущены, используется край строки.

Отрицательный шаг позволяет двигаться справа налево. Срез `[::-1]` поэтому даёт строку в обратном порядке.

## Разделение и замена

`split()` удобно применять, когда строка содержит несколько частей, разделённых пробелами или другим символом. `replace(old, new)` возвращает строку с заменами.

Важно читать условие: иногда нужно изменить только представление текста, а иногда — анализировать исходные позиции. Метод не должен скрывать смысл алгоритма.

## Частые ошибки

- ожидать, что метод изменит исходную строку;
- считать, что правая граница среза включается;
- путать `split()` и разбиение по символам вручную;
- забывать сохранить результат `replace`, `lower` или `strip`;
- применять готовый метод, когда задача требует отработать ручной алгоритм.

## Перед практикой

Для каждого преобразования определите, нужен ли вам новый текст целиком или только конкретный диапазон символов.
