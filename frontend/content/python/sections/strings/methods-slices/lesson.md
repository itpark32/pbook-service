> - Полезно знать: строки неизменяемы: методы возвращают новое значение.

## Методы возвращают новую строку

Методы `.lower()`, `.upper()` и `.strip()` не меняют исходную строку. Результат нужно сохранить или использовать сразу.

```python
text = "  PyThOn  "
clean = text.strip().lower()
print(clean)
print(text)
```

## Срез выбирает диапазон

`text[start:stop:step]` берёт символы до `stop`, не включая правую границу. Отрицательный шаг позволяет идти справа налево.

```python
word = "algorithm"
print(word[0:4])
print(word[::2])
print(word[::-1])
```

## Частые ошибки

Не ожидайте изменения исходной строки после метода без присваивания. В срезе правая граница не включается.
