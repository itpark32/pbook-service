# Строки: символы и индексы

После урока вы сможете перебирать символы строки и безопасно использовать индексы.

> **Фокус**
> - Нужно знать: строка — последовательность символов с индексами от `0`.
> - Нужно уметь: получать символ по индексу и перебирать строку.
> - Полезно знать: последний допустимый индекс равен `len(text) - 1`.

## Символ имеет позицию

```python
text = "python"

print(text[0])
print(text[2])
print(text[-1])
```

`text[0]` — первый символ, `text[2]` — третий, `text[-1]` — последний.

Индекс и сам символ — разные вещи. Индекс отвечает на вопрос «где?», символ — «что находится на этой позиции?».

## Перебор строки

Если нужна сама последовательность символов, удобен прямой перебор.

```python
text = "code"

for char in text:
    print(char)
```

Если задача требует сравнивать позиции или соседние символы, пригодится перебор индексов через `range(len(text))`.

Строка может быть пустой. У пустой строки нет `text[0]`, поэтому обращение по индексу нужно делать только тогда, когда позиция действительно существует.

## Строка неизменяема

Нельзя записать `text[0] = "P"`. Если нужно получить изменённый текст, строят новую строку или используют методы, которые возвращают новый результат.

## Частые ошибки

- считать, что первый индекс равен `1`;
- обращаться к `text[len(text)]`;
- путать индекс и значение символа;
- обращаться к первому символу пустой строки;
- пытаться изменить отдельный символ присваиванием.
