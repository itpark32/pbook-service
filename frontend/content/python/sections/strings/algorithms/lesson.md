# Поиск, подсчёт и преобразование строк

После урока вы сможете решать строковые задачи одним проходом.

> **Фокус**
> - Нужно знать: при проходе по строке состояние хранит результат уже просмотренной части.
> - Нужно уметь: считать символы, проверять пары и строить результат.
> - Полезно знать: выбирайте минимальное состояние, достаточное для следующего шага.

## Подсчёт по условию

```python
text = "a1b23c"
count = 0

for char in text:
    if char in "0123456789":
        count += 1

print(count)
```

После каждого шага `count` означает количество цифр среди уже просмотренных символов.

Такой смысл переменной важнее конкретного имени: он подсказывает, когда и как обновлять состояние.

## Обработка соседней пары

Чтобы рассматривать `text[i]` и `text[i + 1]`, цикл заканчивается перед последней позицией.

```python
text = "ABACAB"
pairs = 0

for index in range(len(text) - 1):
    if text[index] == "A" and text[index + 1] == "B":
        pairs += 1

print(pairs)
```

Для строки длины меньше двух диапазон окажется пустым, поэтому выход за границы не произойдёт.

## Построение нового результата

Если нужно отбросить или заменить отдельные символы, можно накапливать новую строку по мере прохода. При этом полезно формулировать состояние так: «в результате уже находится правильная обработка просмотренного префикса».

## Частые ошибки

- обращаться к `index + 1` на последнем индексе;
- обновлять счётчик вне нужного условия;
- хранить лишние данные, не влияющие на следующий шаг;
- забывать пустую строку и строку из одного символа;
- смешивать несколько разных задач в одном состоянии.

## Перед практикой

Перед циклом закончите фразу: «После обработки первых символов я уже знаю ...». Именно это и должно храниться в переменных состояния.
