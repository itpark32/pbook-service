# Поиск, подсчёт и преобразование строк

> - Полезно знать: после обработки префикса состояние описывает именно этот префикс.

## Подсчёт и поиск

Счётчик из темы циклов работает без изменений: меняется источник данных. Для поиска можно запомнить индекс подходящего символа.

```python
text = input()
digits = 0
for char in text:
    if char >= "0" and char <= "9":
        digits += 1
print(digits)
```

## Преобразование строит новую строку

Строку нельзя изменить по индексу, поэтому результат собирают отдельно, добавляя очередной нужный символ.

```python
text = input()
result = ""
for char in text:
    if char != " ":
        result += char
print(result)
```

## Частые ошибки

Не смешивайте счётчик и индекс найденного элемента. При построении новой строки не теряйте символы, которые должны остаться.
