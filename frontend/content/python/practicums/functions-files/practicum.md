# Практикум 4. Функции, рекурсия и файлы

Разбейте решение на части и примените знакомые алгоритмы к файлам.

## Что здесь проверяется

Параметры, `return`, базовый случай, рекурсивный переход и чтение данных.

## Как работать

Сначала сформулируйте контракт функции или формат строки файла.

## Если застряли

Проверьте один вызов функции или одну строку файла отдельно.
